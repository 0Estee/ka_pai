## 二、作者答复（2026-10-04，逐字）

1.没有问题，就是重新选目标。2.A。3.可以。4.是，但被敌方锦囊选中的敌方单位也会-1攻击力-1生命，范围伤害也算，每次锦囊都触发。5.对，你默认的是对的

对应我问的 5 件事：

1. **克隆**：「触发上一张锦囊的效果」= 重新选目标（不沿用上次选的目标）。
2. **降噪耳机**：选 **A**  光环式（它一离场就恢复；能把 1 血单位压到 0 并消灭）。
3. **连斩（2 点）/ 超重低音（3 点）的「造成N点伤害」**：点选一个敌方单位或敌方国王（火箭弹同口径），可以。
4. **和弦的在手牌中效果**：是  你打出任意锦囊时，被这张锦囊选中的敌方单位各 -1/-1；**范围伤害也算「成为目标」**；**每次锦囊都触发（可叠加）**。
5. **神使**：场上多张时由**生命最低**的那张顶国王的伤害；国王无敌期间不转移（无敌期间本来就不吃伤害）；祈祷的 -2 **先扣再转移**。

## 三、实现计划（引擎侧）

新增阵营 key：剑道 `sword`、音乐 `music`、科学 `science`、神佑 `divine`（已有的 `demon` 恶魔 / `god` 上帝）。
卡 id 从 U408 起：剑道 U408~U412（U410 连斩是令牌）、音乐 U413~U416、科学 U417~U421（U421 新兴研究是令牌）、神佑 U422~U425。
卡定义写进 `data/_transcribe/_cards_O.js`~`_cards_R.js`（O=剑道、P=音乐、Q=科学、R=神佑），
再在 `tools/merge-b3.mjs` 的 `GROUPS` 里加 O/P/Q/R，跑 `node tools/merge-b3.mjs`。

需要新做的引擎能力：
- 费用随本局使用次数（连斩）：记 `players[side].usedCount[cardId]`，`costOf` 加 `+N`。
- 敌方单位数动态伤害（万剑归宗）：amount 加 `{ perEnemyUnit: N }`。
- 一个目标问一次、多效果复用（剑心）：新 op `compound`（`target` + `actions`，子动作里用 `{kind:'compoundTarget'}`）。
- 克隆：记 `players[side].lastSpell`，新 op `repeatLastSpell`（重跑上一张锦囊的 actions，重新选目标；不覆盖 克隆 自身）。
- 前沿科技：`summonToHand` + 新 op `delayedDraw`（下个大回合开始抽 1）。
- 新兴研究（国王被动）：`attachKingEffect` + `onAllyPlayed` 里随机二选一（新 op `randomOne`，走 state.rng）+ 国王被动「手牌 -1 费」（新 op `permanentHandCost`，costOf 读 `players[side].handCostDelta`）。
- 神使：国王伤害转移给生命最低的己方单位（卡级开关 `kingGuard: true`）；「回合开始:+1装甲」= `buffKeywordX`（`armor` 的 X +1）。
- 祈祷：国王本回合每次受伤 -2（`players[side].kingDamageReduce`，state.turn 到期）。
- 诅咒 / 神罚：攻击力永久设为 0 且不能被加成（`unit.atkLocked = 0`，`effectiveAtk` / `buffAtk` 尊重它）。
- 和弦：在手牌中、响应「敌方单位成为锦囊目标」（新触发 `onEnemyTargetedBySpell`）+ 未花费用的提示横幅。
- 降噪耳机：光环支持 `buffMaxHp` + `to:'allEnemies'`（压到 0 要消灭）。
