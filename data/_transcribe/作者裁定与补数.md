# 作者裁定与补数（2026-09 第三批）

## 一、通用裁定

| 问题 | 裁定 |
|---|---|
| 卡面符号 **◈** | **就是攻击力**（与 ⚔ 同义）。所以「+1◈」= +1⚔、「-1◈」= -1⚔、「弹射所有◈<2的单位」= 弹射所有⚔<2的单位 |
| **「弹射」** | **退回其拥有者的手牌**（不是消灭）。「扎根 = 无法被弹射」因此是它的克星 |
| **「复生」** | 复活**回满血**；复活**不触发**「被消灭:」异能，也不触发国王的「友方单位被消灭时」被动 |
| **牌库** | 卡组变成 **80 张**，从**全部卡里随机抽 80 张**（同一局固定、不同局换一批） |
| **「进入一条线」** | **打出**和**被移动**都算进入（抱脸虫落地时也会触发） |
| 交付节奏 | **分两批**：先做「只缺基础能力」的卡出一版 APK，再攻复杂机制 |
