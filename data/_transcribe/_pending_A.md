# 一、完全没录（11 张）

## 1. 致命打击（攻击性锦囊 / 费用 3）
- **卡面效果原文**：`造成3点伤害；使那名单位的生命上限减少3`
- **缺什么能力**：一个「打伤害 + 改同一个目标数值」的**单一动作**（类似 `modifyStats`
  那种「一次选目标、两件事一起做」，只是这次带伤害）。
  眼下拆成 `damage` + `modifyStats` 两个动作也能跑对（界面 main.js:765 与 AI ai.js:430
  都会把同一次点选的 uid 传给每个动作），但按 `骨折` 那条已裁决的口径
  （「两个数值要作用在同一目标上就必须用一个动作」），这里应该补一个
  `damageAndModify`：`{ op, amount, atk, maxHp, target }`。

## 2. 雷电击（攻击性锦囊 / 费用 2）
- **卡面效果原文**：`造成2点伤害,受到此伤害的敌人获-2⚔`
- **缺什么能力**：同 1 ——「对刚刚受伤的那个敌人」再改数值，需要 `damageAndModify`。

## 3. 游击队（单位 / 费用 2 / 攻击4 生命1）
- **卡面效果原文**：`开战回合:获得无敌`
- **缺什么能力**：
  ① 新触发时机 `onCombatStart`（「开战回合:」—— 目前只有回合开始 `onTurnStart`，
     开战结算 `runCombat` 里没有任何触发点）；
  ② **有时限的关键词**：`invincible` 是静态词条（写死在单位的 keywords 里），
     引擎没有「持续一回合」的授予/移除，所以这条只能靠新机制落地。

## 4. 登山员（单位 / 费用 2 / 攻击2 生命2）
- **卡面效果原文**：`在高山上打出获得；+1⚔ +1♥`（两行连读 = 在高山上打出获得 +1⚔ +1♥）
- **缺什么能力**：「打出时检查落点地形」的条件 —— `effects[].when` 只支持 `'fused'`，
  `auras[].condition` 只有 `noOtherAllies` / `hpAbove` / `hpAtLeast`，
  没有任何地方能拿到「这张牌被打在哪条线路」。需要一个条件如
  `when: { lane: 'mountain' }`（山地线路名见 constants.js 的 LANES）。

## 5. 神秘礼物（道具性锦囊 / 费用 4）
- **卡面效果原文**：`抽两张牌,如果是锦囊,则-1花费,如果是单位,则+1⚔+1♥`
- **缺什么能力**：两样都没有 ——
  ① 「按抽到的牌的**类型**分支处理」（条件分支 + 检查刚抽到的那张牌）；
  ② **手牌实例级的费用修正**（「-1花费」，引擎现在一律按卡面定义的 cost 收费）。

## 6. 力量光波（攻击性锦囊 / 费用 9）
- **卡面效果原文**：`造成己方场上队友数×2的伤害`
- **缺什么能力**：**动态数值**。所有 op 的 `amount` 都必须是写死的数字，
  DSL 里没有「按场上数量计算」的数值表达式。
  （转录本身也不确定：`造成` 后那个字疑为「己」也可能是「二」；`数` 后的符号
  辨认为乘号 `×` 也可能是加号 `+`。三个候选都要作者定，但它先卡在动态数值上。）

## 7. 特战旅（单位 / 费用 2 / 攻击2 生命2）
- **卡面效果原文**：`打出:若本回合有其他队友被打出，获+1⚔+2♥`
- **缺什么能力**：**本回合内「已打出队友数」的计数** —— 引擎没有这类事件计数，
  也没有「本回合是否发生过某事」的条件供 `effects[].when` 使用。

## 8. 狂犬病（攻击性锦囊 / 费用 3）
- **卡面效果原文**：`一名队友获得；疾病,并额外攻击一次`（两行连读）
- **缺什么能力**：**「额外攻击一次」不能作为一次动作授予**。
  引擎里只有 `doubleStrike` / `frenzy` 两个**词条**能带来额外攻击，而它们只在
  开战结算里按单位自身的静态词条判定（engine.js 的 collectAttackEvents），
  没有任何「本回合再打一次」的 op。
  只录「授予疾病」会漏掉这张卡的另一半，所以整张不录。

## 9. 魔术师（单位 / 费用 4 / 攻击2 生命3）
- **卡面效果原文**：`打出:让一名敌人变为⚔1♥2的兔子`
- **缺什么能力**：**变形 / 精确设值**。「把目标单位的攻血改成 1/2」需要一个新 op
  （`setStats` 之类）—— `modifyStats` 是加减不是设值；另外还要一只「兔子」的单位定义
  （令牌），卡面只给了 ⚔1♥2，没给费用与词条。

## 10. 鲸鲨（单位 / 费用 4 / 攻击2 生命4）
- **卡面效果原文**：`打出:消灭一名♥最低的敌人`
- **缺什么能力**：**按生命最低择优选目标**。《引擎DSL速查》明确写着过滤器里没有
  「生命最低」这类排序/择优语义，只能靠玩家点选，所以这张牌的目标无法表达。
  （攻/血是作者补的数：2 / 2 / 4，可随时录。）

## 11. 石中剑（单位 / 费用 3 / 攻击1 生命5）
- **卡面效果原文**：`打出:场上每有一名单位这张牌便获+1⚔`
- **缺什么能力**：**动态数值**（同力量光波）——「场上单位数」这个数量没法作为
  `buffAtk` 的 `amount`。光环也不行：`auras` 的 `to` / `condition` 里没有
  「按全场单位数加攻」这一档。

# 四、已录但能力没生效（1 张）

## 火球（攻击性锦囊 / 费用 2 / 词条：暴击1）→ 已录 `U34`
- **卡面效果原文**：词条行 `暴击1`；效果行 `对一名敌人造成3点伤害`
- **现状**：词条写成引擎 id `crit:1`，伤害录成 `damage 3` + `chosenEnemyUnit`
  （照卡面「一名敌人」限定为单位，不给国王）。
- **缺口**：引擎只对**单位**结算暴击 —— `dealDamage` 从 `source` 上取 `crit` 词条，
  而锦囊的伤害 `source` 恒为 `null`（effects.js 的 damage 分支传 `ctx.source`，
  锦囊的 `ctx.source` 是 `null`）。所以这个「暴击1」眼下不会真的掷骰。
- **需要的能力**：让**锦囊自己的关键词**参与伤害结算（把卡牌定义当成伤害来源，
  或给 `damage` 动作加 `keywords` 字段）。补上之后 `U34` 自动生效，不用改卡。
