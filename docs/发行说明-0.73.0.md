# 发行说明 0.73.0

## 改动

### 「融合」与「融合进化」拆成两条词条（作者 2026-10-25）

以前只有一个词条，叫「融合进化」，但实际被装的是 0.72.0 的融合新口径。现在拆开：

| 词条 | 打法 |
|---|---|
| **融合** | 打在队友身上 → **融合牌自己被消灭**、队友留在场上；也可以把普通单位打在带融合的队友身上 → 新牌留下、带融合的那张被消灭。融合后效果结算在**留场的那张牌**上（裁决 D78） |
| **融合进化** | 打在队友身上 → **队友「消失」**（进弃牌堆，但不触发任何被消灭效果）、新牌顶替它。卡面「融合进化:…」的效果落在**新打出的那张牌**上（裁决 D34，原样保留） |

卡面带「融合进化:…」的三张（跳杆运动员 / 霸王龙 / 雪人）一个字没改，行为回到 0.72.0 之前。

### 六条修正（作者 2026-10-25 试玩报告）

1. **第5伞兵旅**：回合开始「弃置一张手牌」现在会**问你弃哪一张**。以前是引擎自动代答、
   等于「弃掉手牌最左边那张」，玩家从头到尾没被问过。
2. **沧龙**：改成**消灭自己线上和相邻线上的所有敌人，自己不消灭**。
   以前读成「消灭自己 + 相邻线路的敌人」，既自杀、又打不到自己这一路。
3. **红火蚁**：打出时「获得-2♥」扣掉的血**也算「扣除♥」**，会触发它自己的异能
   （以前只有挨打才触发）。新增触发时机 `onHpLost`，数值修改扣血与伤害走同一个触发；
   数值修改仍然**不是伤害**（D25 不变：不惊动装甲 / 祝福 / 荆棘 / 观察者）。
4. **开战时的选择**：狙击手这类「开战要选目标」的异能，现在会**等玩家选完才开打这一线**。
   以前挂起请求被吞在结算内部，这一线先打完、面板才弹出来，选中的目标早就死了。
5. **狂热**：额外攻击又消灭了敌人，会**再触发一次狂热**（裁决 D80 修订 B10）。
   双重打击仍然每回合固定 1 次，不连锁。
6. **先手开局看不到手牌**：修了入场铺开的步数 —— 棋盘其实有 6 行（含线路表头），
   而步数写死成 6，最后一步被「我 后排」吃掉，手牌永远停在不可见状态；
   先手开局没有任何重绘来纠正，所以只有先手会卡死。现在按真实行数算。
