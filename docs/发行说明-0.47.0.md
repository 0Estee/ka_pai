# 0.47.0

## 改动

**菜单逐级切换的滑动动画**
- 前进（主菜单  二级  三级）：旧页面先向右让一小步，再向左划出屏幕；新页面从右侧滑入。
- 返回：方向全部相反。
- 方向由屏幕层级自动决定，所以以后加新页面只要登记层级，动画不用另写。

**开局入场**
- 进入对局时棋盘从上往下一行行铺开，手牌从下方逐张滑入（每行 / 每张错开约 40ms）。

**交战不再整行闪**
- 以前每次攻击会把整条线路高亮一下，现在是只渲染这一下真正参与的卡牌：出手方前冲、挨打方抖动掉字，
  国王挨打只抖国王。线路不再整体闪烁。
