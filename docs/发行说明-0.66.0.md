# 发行说明 0.66.0

> 这一版四件事：**靶场**（试卡用的沙盒）、联机**重新开局**、**手牌**改回账本语言、阵营**介绍**。
> 对局规则本身没有改动（引擎只多了一个「靶场」旁路与伤害原因字段）。

## 1. 靶场（开始游戏 → 靶场）

用来**试卡**：改完一张牌，进来点两下就能看到它在场上的样子，不用凑费用、不用等抽牌。

- **点任意格子**：先点一张手牌，再点场上**任意一格**——
  点自己那一侧就放在自己这儿，点对面那一侧就放到对面（对面格子也算）。
  锦囊同理：点任意单位 / 国王 / 线路，就是把它打过去（打自己人也行）。
- **开局全发**：双方进来就把本阵营**全部超能力**拿到手（不是按国王血量一张张抽）。
- **换阵营**：工具条上「我方 / 对方」两处都能换，换了立刻补发新阵营的全部超能力
  （旧牌留在手里，方便两家的牌对着试）。
- **换难度 & AI 开关**：难度只影响「AI 行动」打开时对面那一侧的水平；默认**待机**，
  摆好的局面不会被程序立刻打散。
- **切换到对面**：「控制 玩家1/2」换的是视角与输入归属，两边仍是同一局。
- **加牌**：打开整个卡池（按阵营分组），点一张就进手牌——试哪张都行。
- **清空场地 / 重置靶场**：清空只清格子（手牌与国王血量不动），重置是整局重来。
- 靶场**不判胜负、不发金币、不进回放**：国王打到 0 就停在 0，对局继续。

## 2. 伤害原因（每次受伤都写清楚）

引擎在写伤害日志时就把**原因**一起记下来，界面直接用，不再自己猜：

- 格子上的掉字下面多一行小字：`-3` / `火炮 交战`；
- 国王血条的掉字同理；
- **战报 / 菜单**里现在也有「受伤 −N（山地前排，『毒镖』）」这样的整行；
- 点场上任意单位，详情面板底部多一块「最近受伤」，列出最近 4 下的数值与原因。

原因的口径：交战伤害是「**卡名 交战**」，锦囊是「**「卡名」**」，标记结算写「中毒 / 灼烧 / 国王中毒」，
反弹与转移写「荆棘反弹（卡名）/ 神使替伤 / 巫毒娃娃转移」。

## 3. 联机可以「重新开局」

菜单 → **重新开局**：

- **房主**按：重新算一份开局参数（种子 / 牌库 / 双方阵营 / 强化）并广播 `start`（带 `r:1`），
  两端一起重建这一局 —— 走的就是当初开局那条路，所以不会出现「两端跑不同的对局」。
- **客人**按：发一条 `restart-req`，由房主真正执行（重开只能有一个人算参数）。
  房主收到会弹一条提示并立刻重开。
- 以前这里被写成「点重开＝退出房间」，原因是怕两端各开各的；现在重开也走开局协议，安全了。

## 4. 手牌样式跟上全局设计

手牌原来还停在 0.62 那一套「胡桃木渐变 + 金边 + 内发光 + 金色费用球」，
和 0.64 定下的账本皮肤是两套语言。这一版把它整块重画：

- 平面纸色（比底色亮一档）+ 1px 线，没有渐变、没有内框、没有反光；
- 费用是一个衬线数字，不再有金球；
- 名字、攻防数字都用衬线，攻击/生命之间一条 hairline；
- 「超能力 / 原料」角标改成线框小字；
- **唯一的金**留给「选中的那一张」。

## 5. 阵营介绍

「AI 难度与阵营」里每个阵营右边多了一个「介绍」按钮：
展开写的是**这套牌靠什么赢**、关键牌是哪几张，并列出该阵营全部超能力的牌名
（名单从卡池现取，以后加牌不用改这段）。
