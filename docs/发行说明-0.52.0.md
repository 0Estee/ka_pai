# 0.52.0

## 改动

- 新增「炼金」阵营：每抽一张牌得一份原料（金沙 / 厄毒之尘 / 陨铁 / 硫磺；原料堆 14 张，抽干不补）。
- 原料可以多张一起炼药：按消耗掉的原料组合产出一张令牌（11 种组合），费用 = 消耗原料各自费用之和；组合对不上不给令牌、费用照付。
- 令牌 11 张：玄剑 / 财富药水 / 湮灭药水 / 生命药水 / 棘刺之甲 / 高爆药水 / 狂热药水 / 精致金甲 / 毒雾药水 / 毒爆药水 / 事故（加入手牌即自动使用，然后结束当前出牌回合）。
- 非令牌超能力 4 张：巫毒娃娃 / 未收录粉尘 / 解禁 / 炼金潮。
- 界面：手牌里的原料带「原料」角标，阶段栏（结束回合左边）出现「炼药」按钮，顶栏显示原料堆张数；选原料会提示花费与将产出的令牌。
- AI 会用炼金阵营炼药；炼药动作进锁步、回放与联机同步。
- 规则测试 126 到 137；新增炼金门禁 6 条。
