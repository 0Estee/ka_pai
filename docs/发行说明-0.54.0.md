# 0.54.0

## 改动
- 新增三个阵营，共 17 张卡（U445-U461，含 5 张令牌）：
  - 炼狱「越烧越旺」：狂热、溅射与全场横扫的火焰
  - 极寒「冻结敌人的下一次攻击」：再对被冻住的目标追加伤害
  - 罪恶「捕猎与掠夺」：抢走对手的手牌，用生命换生命
- 卡牌被弃置时（含被对手抢走），从手牌缓慢飞向屏幕下方。
- 修掉一个会污染卡库的引擎 bug：单位身上挂的异能写进了卡面定义，导致同名牌在之后的对局里自带该异能。
- 门禁新增三阵营检查：难度页十个阵营、17 张新卡与令牌标记、三个新阵营整局自走都能终局。
