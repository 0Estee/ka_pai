## A 级 · 阻断项（8 条）

### A1. 共享牌库总张数
**影响**：直接决定对局时长。起手消耗 9 张，之后每回合消耗 2 张。
**推算**：40 张 → 剩 31 张 → 约 **15 回合**（费用上限到 15）；30 张 → 约 10 回合。
**建议**：**40 张**（对局约 15 回合，费用曲线的后半段能用上）。

### A2. 牌库抽空判定
**建议**：牌库抽空时，**该回合结束时国王生命值高的一方获胜**；若相同则平局。
（备选：需要抽牌但牌库为空的一方**立即失败**。）

### A3. 双方国王同时归零
**建议**：判定**平局**。

### A4. "弹射"和"移动"是未定义机制 ★
**问题**：`扎根`"无法被移动，无法被弹射"；`无敌`"无法受到伤害或被弹射"。规则里**没有这两个机制**。这是原始口述时漏写的部分。
**建议（v0.2 做减法）**：
- **删除"移动"**：v0.2 无移动需求，`扎根` 改为"**无法被弹射**"。
- **定义"弹射"** = 将该单位**返回其拥有者手牌**。这样 `扎根`（免疫回手）和 `无敌`（免疫回手）都恢复意义。

### A5. 无回合上限
**建议**：第 **30** 回合结束后，国王生命值高者获胜，相同则平局。

### A6. 多单位配对 ✅ 已裁决（D8）
**结论**：我方同线前后排共 2 个单位时，**两个都攻击敌方前排**（伤害叠加）。
引擎已实现，见 `docs/规则书-v0.2.md` §8.4。

### A7. 攻击力为 0 的单位 ✅ 已裁决（D9）
**结论**：**仍然阻挡**，只是不造成伤害。引擎已实现。

### A8. 原型需要测试卡 ✅ 已处理
已产出 `engine/cards/test-cards.js`：每个词条各 1 张 + 若干白板单位，纯数字、无美术、即用即弃。
等你提供正式测试卡牌时直接替换该文件。

## B 级 · 重要歧义（16 条）

### B1. 锦囊的目标规则
**已修订**：卡面只写「造成X点伤害」而不限定目标时，**可以选择国王作为目标**（作者裁决）。卡面写明「敌人 / 敌方单位」的（如「滚石」）仍然只能选单位。引擎用 `chosenEnemyTarget` 选择器表达这种复合目标。

### B2. 水生单位离开水路
v0.2 无移动机制，暂时不会发生。**建议**：留作待定，二期处理。

### B3. "费用上限增长"是永久还是本回合
**建议**：**仅本回合**。若是永久，卡面必须显式写"永久"。

### B4. `溅射` / `穿透` 命中后排的数值
**建议**：`溅射 X` = 相邻线路所有敌方单位（**含后排**）各受 X 点伤害；`穿透 X` = 本线路额外 X 个敌方单位（**含后排**）各受**等同于攻击力**的伤害。

### B5. 额外攻击（`双重打击`/`狂热`）时若前线已清空
**建议**：攻击**敌方国王**。若敌方后排也想打，需要该次攻击本身带 `溅射`/`穿透`。

### B6. `祝福` / `装甲` / `荆棘` 的结算顺序 ★
**建议固定结算链**：
```
原始伤害
  → 祝福X：若伤害 > X，设为 X     （先封顶）
  → 装甲X：伤害 - X                （再减伤）
  → 得到「最终伤害」
  → 荆棘X：按「最终伤害」对来源反弹
```
补充：荆棘反弹会被对方的 `祝福`/`装甲` 修正，但**不再触发荆棘**（防无限循环）。

### B7. `淬毒` 与 `无敌` 冲突
"无视任何机制" vs "无法受到伤害"。
**建议**：**`无敌` 优先**，免疫一切伤害（含淬毒）。但**不免疫"消灭"**——`疾病`/`献祭` 可以消灭无敌单位，给无敌留一个克星。

### B8. `淬毒` / `疾病` 的"下回合开始"
**建议**：在**该单位当前控制者**的回合开始阶段（费用重置那一刻）结算。若结算时该单位已不在场上，效果**落空**。多层 `淬毒` **可叠加**、各自独立结算。

### B9. `暴击` 的连锁
**建议**：`暴击` 的额外伤害**不触发** `造成伤害:` / `淬毒` / `暴击`（防无限连锁）；`暴击` **对国王生效**。

### B10. `双重打击` + `狂热` 连打
**建议**：**每个单位每回合最多触发 1 次额外攻击**，无论拥有几个此类词条、杀死了几个敌人。（防 OTK 的关键阀门）

### B11. `穿透 X` 的伤害数值
**建议**：额外命中的每个敌方单位各受**等同于该单位攻击力**的伤害；溢出打国王同样造成**一次攻击力**的伤害。

### B12. `飞行` 名实不符 ✅ 已裁决（D10）
**结论**：**改名 `轻灵`**，效果不变（血量 ≥ 上限一半时获得两栖，否则失去；在水路失去时被消灭）。

### B13. `扎根` / `无敌` 引用的"弹射"未定义 ✅ 已裁决（D11）
**结论**：`弹射` = **返回拥有者手牌**；「移动」机制删除，`扎根` 改为"无法被弹射"。

### B14. `献祭` 的定位
已按"**机制动作**"归档（非词条），由卡牌文本触发，例如 `打出: 献祭一个友方单位，然后抽 2 张牌`。**已实现**：不可献祭自身。

### B17. ⚠️ 新发现：`造成伤害:` 异能会自我无限触发
**问题**：`造成伤害:` 的触发条件是"该单位对其他单位造成伤害时"。如果某单位的 `造成伤害:` 异能是"对敌方单位造成 X 点伤害"，那么这次伤害**又满足触发条件** → 无限递归。
原文没有任何限制。
**引擎处理**：已加护栏 —— **由 `造成伤害:` 异能自身造成的伤害，不再触发任何"造成伤害时"的词条**（暴击 / 淬毒 / 疾病 / 造成伤害:）。
**副作用**：需要知悉 —— 一个同时拥有 `淬毒` 和 `造成伤害:` 异能的单位，其异能造成的伤害不会触发淬毒。若你不接受这个副作用，需要另行规定（例如"每回合每单位最多触发一次"）。

### B15. 多个触发同时满足时的结算顺序
**建议**：由**当前回合玩家**决定其一方全部触发的结算顺序；双方同时触发时，当前回合玩家的效果先入结算栈。

### B16. 锦囊的目标规则 ✅ 部分修订（D16）
先手起手 5 张、后手 4 张，但每回合抽牌时**后手先抽**。即便如此先手仍占优（先部署）。
**建议**：原型跑 20 局统计数据后再调，**先不改**。
