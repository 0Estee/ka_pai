# 发行说明 · 0.65.0

> 三件事，都在战斗演出上：**给每一种受击动画补上"源头"**、
> **被打死的那张牌也要挨爪印**、**爪印大小跟着伤害走**。

---

## 1. 动画没有源头 → 每一次受击都从出手的那张牌"挠过来"

以前爪印、掉字、退场全都只画在**结果**上：一张牌凭空抖了一下、掉了个数字、
然后倒了 —— 看不到这一下是谁打的。

现在每一记伤害在落爪之前，会先从**出手的那张牌**拉出三道爪痕（`.fx-rake`）
扫到目标身上，爪痕到了才落爪印：

* 起点优先级：日志里最近一条 `lane-combat` 的 `attackers`（它还在场上就画它）
  → 对面半场同一路的前排 / 后排 → 对面状态条（锦囊 / 陷阱这类没有出手单位的伤害）；
* 落点用**格子**（`.slot[data-lane][data-side][data-row]`），不是单位节点 —— 这样
  "这一下把人打死"也能画，因为那时单位已经不在 state 里了；
* 爪印的等待不是 `setTimeout`，而是写在自己的 `animation-delay` 里：
  节点当场就建好（自检能断言），也不怕中途一次重绘把定时器漏掉。

## 2. 卡牌被打死时没有爪印

根因：爪印要挂在 `.unit[data-uid="X"]` 上，而**致死的那一下，单位已经不在 state
里了** —— 格子里画的是"阵亡残影"（`.unit.ghost`），它当时没有 `data-uid`，
于是 `querySelector` 找不到人，爪印整块被跳过。

修法不是给残影补 `data-uid`（那会让"点场上单位看详情"点到一块残影，也会把死人
混进按 uid 收集的名单），而是**爪印改成按格子定位**：格子在阵亡前后都在，位置也对。

## 3. 爪印大小跟着伤害走

以前 1 点和 8 点是同一块几乎盖满卡面的爪印，"小刀划一下"和"一记重击"一样重。现在：

| 这一下 | 爪印相对卡面 |
|---|---|
| 1 点 | **0.68×**（浅浅一道） |
| 5 点 | **1.16×** |
| 5 点且致死 | **1.32×**（再大一档） |

`0.56 + 伤害 × 0.12 + 致死 0.16`，钳在 0.62 ~ 1.75 之间（不会小到看不见，
也不会铺满整屏）。爪痕本身的三道线也按同一把尺变粗。

## 回归测试

`tools/checks/44-combat-fx-source.mjs`：

1. 残影**不带** `data-uid`，且 `spawnClawFx` 必须按**格子**找落点（源码级守住）；
2. 爪印大小单调：1 点 < 5 点 < 同一记 5 点在致死时，且越界钳制有效。

另有真浏览器探针（`?demo=fxprobe`）会在真对局里量出：
爪痕起点到出手牌中心的距离（1px）、爪印落点是否在被打死的那一格、
爪印相对卡面的倍数 —— 上面那张表就是它量出来的。
