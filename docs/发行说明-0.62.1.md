# 发行说明 · 0.62.1

> 修两个 0.62.0 的问题：金色太晃眼、浅色 / 玻璃模式有显示 bug、
> 放置卡牌时对方格子也被点亮。

---

## 一、收光（太晃眼）

0.62.0 的金色太亮了：顶光、主按钮镜面、卡牌边框、选中光晕、徽记发光全部叠在一起，
深色模式下像打了闪光灯。

这一版只做一件事：**把光压下来**。

- 标题从「白金反光」改成旧金浮雕，去掉大范围黑投影；
- 主按钮去掉镜面高光，压成暗黄铜；
- 卡牌边框、费用宝石、选中光晕全部降饱和降亮度；
- 桌面顶光收一半；
- 选中卡只留一圈薄光，不再发光带投影；
- 徽记发光、金币发光、进度条发光全部去掉。

| 指标 | 0.62.0 | 0.62.1 |
| --- | --- | --- |
| 首页平均亮度 | 25.3 | 24.7 |
| 首页最亮 1% 像素 | 179.2 | 167.5 |

## 二、浅色 / 玻璃模式的显示 bug

0.62.0 把深色 HUD（顶栏 / 状态条 / 阶段条 / 提示条）的字跟着主题变量一起染成了深色，
浅色和玻璃模式下直接读不出。

这一版把这些**深色条上的字固定成浅色**，不再跟主题走；
浅色 / 玻璃模式的提示条、错误条单独改成浅底深字。

## 三、对方格子高亮

放置卡牌时，敌方半场的同名格子也会亮起 —— 是 `picked` / `drag-over` 两个状态
没判断格子归属。0.62.1 补上了 `mine` 守卫，并加了门禁（§ 41 放置高亮）。
