# 0.50.0

## 改动

- 开局入场动画改为「从上往下一行一行出现」：进度由 JS 逐格推进（每 90ms 露出下一行），出场动画只由元素的 data-in 属性从 0 翻成 1 触发。渲染出的 HTML 永远不带这个入场标记，所以开局阶段后续的整块重绘不会再让动画从头重放——此前就是被自动阶段（260ms）与 AI 回合（420ms）的刷新反复重放，看起来像「卡一下、重新渲染了一遍」。
- 还没轮到的行照常渲染在场景里（只是不可见），铺开不改变布局，棋盘不会跳。
- 铺开结束后仍是原来的观感（5 行棋盘 + 手牌依次入场），只是节奏改由 JS 控制。
