# 发行说明 0.67.0

> 这一版只做一件事：**联机观战**。对局规则、牌、AI 一行都没动。

## 观战是什么

联机对决多了第三条连接：观战者。它和两位玩家跑**同一局**（收同一份 start、同一串操作），
所以看到的棋盘、血量、战报和玩家那边逐格一致 —— 不需要另传一份棋盘。

但它和玩家有三条硬区别：

| | 玩家 | 观战者 |
|---|---|---|
| 占座位 | 是（1 / 2） | 否（来几个都行） |
| 能发操作 | 是 | **不能**（服务端 403，客户端也挡） |
| 手牌 | 自己那份 | 默认看不到（只报双方张数） |
| 金币 / 回放 | 结算 | 不结算、不录 |
| 谁推进回合 | 主机 | **谁都不推**，只跟着收到的操作走 |

## 怎么用

1. 开始游戏 → 联机对决 → **观战**；
2. 填房间号（公网，例如 `K7QM2P`）或主机地址（同一 Wi-Fi，例如 `192.168.1.7:8765`）；
3. 连上后是「观战中」页，两位玩家一开局，画面自动出来；
4. 顶栏那颗「公开手牌」可以把手牌摊开看（只画玩家1那一手，而且点不动 —— 那是给作者试牌用的）；
5. 菜单里只有「退出观战」，没有「重新开局 / 认输」。

观战者**来去都不影响对局**：两端不会因为「有人进来」被判成掉线；
只有两位玩家都走了，观战才会结束（那时候显示「连接已断开」）。

如果房间已经打很久（房间日志只留最近 600 条），开局信息可能已经被裁掉 ——
这时会明确告诉你「进不来观战」，而不是让你对着「等待这局开始…」干等。

## 这次改了哪些地方

- **Cloudflare 房间服务（`cloudflare/src/room.js`）**
  `who=watch` 是一条新的连接类型：`/api/send` 直接 403、`/api/poll` 只在**两端都离开**时回 peer-left、
  `/api/start` 忽略、`/api/room` 带 `watchers` 人数；每一轮回包也顺带报一次人数，
  大厅上那行「有 N 人在观战」就是它。
- **局域网服务（`android/.../net/HttpGameServer.java`）**
  同一套语义用 Java 实现了一遍（`WHO_WATCH`）。这次**有桌面测试**：
  `android/test/java/.../SpectatorTest.java` 把真服务拉起来用真 HTTP 打了一遍，11 项全过。
- **客户端会话（`app/js/multiplayer.js`）**
  `Session` 多了 `isWatcher`：不提交操作、不要补齐（need）、不比对指纹、不发 bye；
  缺一条 act 时等下一轮 poll 自己补回来（它发不出请求）。
- **界面**
  联机菜单多了「观战」；新增两屏（观战入口 / 观战中）；观战时的棋盘复用对局那套渲染，
  但所有操作按钮都是禁用的，手牌区换成一行「观战 · 手牌不公开」。
