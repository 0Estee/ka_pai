# 0.44.0

## 改动

- 场上单位的攻击力 / 生命改成宝石徽记：攻击是蓝四角星、生命是红盾牌，数字压在宝石上，用真描边（外深内亮两层）保证深色 / 浅色 / 玻璃三套主题下都读得清。
- 单位受伤时，生命盾上补出 /上限（原来跟在数字后面的小字）。
- 阵亡残影也换成同款徽记。
- 旧的「剑 / 心」属性文本行与对应样式已删掉，卡片底部改成左右两角的徽记定位。
- 新增打包校验：源码引用的图片资源必须在 APK 内；徽记本身要能解码、128x128 带透明通道、攻击偏蓝 / 生命偏红。
- 新增回归检查 26（属性徽记）：宝石资源、三套主题的徽记变量、场上单位与残影的标记、受伤时的 /上限 都锁住。
