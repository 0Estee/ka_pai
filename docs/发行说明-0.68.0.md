# 发行说明 0.68.0

> 这一版是五条反馈的修正：靶场两手（强化模式入口、换阵营收牌）、靶场任意落点、
> 观战去手牌区 + 可切视角。对局规则一行没动。

## 1. 强化模式也有靶场

`强化模式` 菜单里多了一个「靶场」入口。和普通模式的靶场是**同一套工具**（任意摆牌、
超能力全发、换阵营 / 换难度 / 换控制方 / 加任意一张牌 / 清空场地），区别只有一条：

* 这个靶场里**强化与精通真的生效**（我这一侧读档案，对面按难度 + 局内种子确定性生成），
  所以试的是「强化之后长什么样」，不是卡面原值；
* 普通模式的靶场仍然完全读卡面原值 —— 强化是独立模式，两边互不影响。

## 2. 靶场换阵营会收走上一个阵营的牌

以前换阵营只补发新阵营那一整套，旧的留在手里，换个阵营得自己一张张丢。
现在换阵营时，**上一个阵营的牌会从手里收走**，只留当前阵营那一整套；
提示行会写清楚「发 N 张，收走上一个阵营的 M 张」。

场上已经摆出去的牌不动 —— 那是摆好的局面，不是手牌。

## 3. 靶场任意格子都能放牌

三条一起改：

| 情况 | 以前 | 现在 |
|---|---|---|
| 格子里已经有单位 | 提示「先清空场地」 | **直接顶掉**（旧牌消失，不算被打死、不触发被消灭效果） |
| 对面那一侧的格子 | 能放，但不亮 | 两边半场都亮（点哪边就放哪边，拖动一致） |
| 中间那行陷阱格 | 单位牌会塞进一个 `undefined` 格子（画不出来也点不到） | 陷阱牌 → 埋伏在**点的那一条线路**；单位牌 → 明确提示「陷阱格只放陷阱牌」 |

## 4. 观战不显示手牌格子

观战画面里**整块手牌区都不画了**（一个格子都没有）。双方还剩几张牌看状态条上的
「手牌 N」就够 —— 手牌区对旁观者只是一块占屏幕的空地。

## 5. 观战可以切换视角

顶栏多了一颗「视角：玩家1」按钮，点一下把玩家2 摆到下面看，再点回玩家1。
棋盘上下半场、行标签（`玩家1 前排` / `玩家2 后排`）、状态条都跟着翻。

只翻界面：不发明消息、不动对局状态、不推进回合 —— 观战者仍然只是照抄收到的操作。
