# 卡牌游戏 规则书 v0.1

> 由作者口述规则整理而成，**不添加任何我自己的设计**，只做结构化和去歧义。
> `【待定-XX】` = 规则空缺或存在歧义，需作者裁决。完整清单见 [裁决清单.md](裁决清单.md)。

---

## 0. 术语表

| 术语 | 定义 |
|---|---|
| 国王 | 每方核心，生命上限 20。生命 ≤ 0 时该方失败 |
| 单位 | 卡牌类型之一。拥有攻击力与生命，进入战场后驻留 |
| 锦囊 | 卡牌类型之一。分为道具性锦囊与攻击性锦囊（图标不同）。效果发动后消失 |
| 费用 | 使用卡牌需支付的资源。上限随回合数增长 |
| 线路 / 路 | 战场横向分 4 路，从左到右：**山地 → 平地 → 平地 → 水路** |
| 排 | 战场纵向分 5 排，**中间一排为陷阱格**。`【待定-A3】` 其余 4 排作用未定义 |
| 词条 | 卡面上**带下划线**的关键词，规则内建 |
| 异能 | 单位自身的效果，分为触发式与静态两类 |
| 消灭 | 单位离开战场 |
| 弹射 | `【待定-A8】` **规则中未定义此类机制**，但被词条引用 |
| 移动 | `【待定-A8】` **规则中未定义此类机制**，但被词条引用 |

### 异能的发动时机标注

| 卡面标注 | 发动时机 |
|---|---|
| `打出:` | 该单位由手中进入战场时 |
| `被消灭:` | 该单位被消灭时 |
| `造成伤害:` | 该单位对其他单位造成伤害时 |
| （无标注） | 该单位在场期间**始终有效**（静态/光环） |

## 1. 对战目标

- 双方各有一个国王，**生命上限 20**。
- 国王生命值 ≤ 0 时，该方失败，另一方胜利。
- `【待定-A5】` 双方国王同时归零时的平局判定未定义。
- `【待定-A6】` 牌库抽空时的处理未定义。
- `【待定-A7】` 卡组构筑规则（牌库张数、同名卡上限）完全未定义。

---

## 2. 卡牌

### 2.1 通用
- 卡面**左上角**为卡牌类型：`单位` / `锦囊`。
- 使用任意卡牌都需要支付费用（见 §5）。

### 2.2 单位
- 属性：**攻击力**、**生命**。
  - 攻击力 = 一次攻击可造成的**基础伤害**（"基础"二字暗示存在加减修正，但修正规则未定义）。
  - 生命 = 可承受的伤害；生命 ≤ 0 时该单位被消灭，离开战场。
- 多数单位拥有异能，按 §0 的时机标注发动。
- 词条以**下划线**标注（词条总表见 §7）。

### 2.3 锦囊
- `道具性锦囊` 与 `攻击性锦囊`，二者图标不同。
- 效果发动后消失。
- `【待定-B16】` 锦囊的目标选择规则未定义（是否可指定国王？攻击性锦囊是否只能打单位？"锦囊免疫"词条暗示锦囊有指定目标机制）。

---

## 3. 战场

### 3.1 线路
```
        山地  |  平地  |  平地  |  水路
敌方  [  ...  ] [  ...  ] [  ...  ] [  ...  ]
      -----------------------------------------
      [        陷阱格（中间一排）        ]
      -----------------------------------------
我方  [  ...  ] [  ...  ] [  ...  ] [  ...  ]
```
- 双方在每条线路上**一般情况**可各放置 1 个单位。
- `【待定-B13】` "一般情况"的例外清单未列出（已知例外：`组合`；未知例外：陷阱、飞行、未知机制）。
- 同一线路上**攻击力不为零**的单位在开战后**互相攻击**。
- `【待定-A4】` 一条线路上出现多对多单位时的目标分配规则未定义（`组合` 可造出 2v2）。

### 3.2 排与陷阱格
- 战场纵向分 5 排，中间一排用作**陷阱格**。
- `【待定-A2】` **陷阱机制完全空缺**：无陷阱卡牌类型、无放置时机、无明置/暗置规则、无触发条件、无触发时机。这是规则中最大的空白。
- `【待定-A3】` 除中间排外，其余 4 排的作用未说明；单位是占据"一路"还是"一路 × 一排"未说明。

## 4. 回合流程

开始游戏：随机决定先后手 → **先手抽 5 张牌，后手抽 4 张牌**。
（原文"抽牌时后手先抽，先手后抽"与上句并列，指向存在**每回合抽牌**步骤，但流程中缺失。`【待定-A1】`）

每个回合分为 **5 个部分**：

| 序号 | 部分 | 阶段限制 |
|---|---|---|
| 1 | 先手放置单位 | 一般不可打出锦囊 |
| 2 | 后手放置单位 | 一般不可打出锦囊 |
| 3 | 先手打出锦囊 | 不可打出单位 |
| 4 | 后手打出锦囊 | 不可打出单位 |
| 5 | 开战 | 按山地 → 平地 → 平地 → 水路的顺序依次开战 |

- `【待定-B15】` 部分 1、2 中"**一般**不可打出锦囊"的例外是什么？
- `【待定-B14】` 费用在 5 个部分之间是否共享？（按 §5"回合开始时将费用设为费用上限"推断为**共享**，即一个回合内放置与锦囊共用一个费用池，不重置、不结转。）

---

## 5. 费用

- 费用上限随回合数增长：**第 1 回合为 1，第 2 回合为 2，以此类推**。
- 部分卡牌可增长费用上限。
- **回合开始时，将当前费用设为费用上限**。
- 若使用的卡牌花费 > 剩余费用，则该卡牌无法使用。
- `【待定-C5】` 卡牌造成的"上限增长"是永久还是仅本回合？增长时是否立刻补满当前费用？

### 费用的关键推论（需作者确认）

第 1 回合费用上限为 1，且放置阶段与锦囊阶段**共享**这 1 点费用，因此：

> **第 1 回合每位玩家只能打出 1 张 1 费卡牌，无法同时放置单位和打出锦囊。**

---

## 6. 开战结算

1. 按 **山地 → 平地 → 平地 → 水路** 的顺序，逐线路结算。
2. 同一线路内：
   - 双方**攻击力不为零**的单位**互相攻击**。
   - 若该线路上**没有敌方单位**，则攻击**对方国王**。
3. `【待定-B8】` 攻击力为 0 的单位的处理未定义（它不攻击，那它是否会被对方攻击？若一方为 0 攻，另一方是否算"线路无敌方单位"从而可以打国王？）
4. `【待定-B17】` 交战伤害是否**同时结算**？（`双重打击`、`狂热` 的措辞暗示是同时结算：双方同时造成伤害 → 判定存活 → 再额外攻击。需写死。）
5. `【待定-B18】` 跨线路的顺序结算 + `溅射` 会造成不对称：山地先结算，其溅射可以把平地单位在平地结算前打死。需确认这是有意设计。
6. `【待定-B9】` `造成伤害:` 定义为"对其他**单位**造成伤害"，因此**打国王不触发**该异能；需确认。

### 回合示例（第 1 回合，费用上限 1）

- 部分 1：先手花 1 费打出 `1费 1/2` 单位到**山地**，费用归 0。
- 部分 2：后手花 1 费打出 `1费 2/1` 单位到**平地**，费用归 0。
- 部分 3、4：双方费用均为 0，锦囊阶段无事发生。
- 部分 5 开战：
  - 山地：先手有单位、后手无 → 先手单位攻击后手国王 **1** 点。
  - 平地：后手有单位、先手无 → 后手单位攻击先手国王 **2** 点。
  - 其余线路双方皆空，无事发生。
- 结算后：先手国王 18，后手国王 19。

## 7. 词条总表

结构化版本见 [词条表.csv](../data/词条表.csv)。以下为口述原文的结构化整理。

| 词条 | 参数 | 类别 | 触发时机 | 效果 |
|---|---|---|---|---|
| 双重打击 | — | 触发 | 交战且未被消灭后 | 额外再攻击一次 |
| 狂热 | — | 触发 | 交战并消灭敌方单位且未被消灭后 | 额外再攻击一次 |
| 疾病 | — | 触发 | 对敌方单位造成 > 0 伤害后，且该单位未被消灭 | 在下回合开始时将其消灭 |
| 装甲 X | X | 替代 | 受到伤害时 | 使受到的伤害减少 X |
| 荆棘 X | X | 触发 | 受到伤害时 | 对伤害来源造成 X 点伤害 |
| 祝福 X | X | 替代 | 受到伤害时 | 若此伤害 > X，则设定此伤害为 X 点 |
| 水生 | — | 静态（打出限制） | 打出时 | 只能在水路打出 |
| 两栖 | — | 静态（打出限制） | 打出时 | 可在水路打出 |
| 飞行 | — | 静态（动态） | 持续 | 生命值 ≥ 1/2（向上取整）时获得两栖；否则失去两栖，然后若其在水路，将其消灭 |
| 锦囊免疫 | — | 静态 | 持续 | 无法作为锦囊牌的目标 |
| 暴击 X | X | 触发 | 造成伤害时 | 50% 几率额外造成 X 点伤害 |
| 扎根 | — | 静态 | 持续 | 无法被移动，无法被弹射 |
| 无敌 | — | 静态 | 持续 | 无法受到伤害或被弹射 |
| 组合 | — | 静态 | 持续 | 在场时可在其所在线路上再放置一个单位；可在场上已有友方单位的线路打出（每条线路最多 2 个友方单位） |
| 献祭 | — | 动作？ | 未定义 | 指定一个友方单位，将其消灭 |
| 溅射 X | X | 触发 | 发动攻击时 | 对相邻的左右各一条线路上的**所有**敌方单位造成 X 点伤害 |
| 淬毒 X | X | 触发 | 造成 > 0 伤害时 | 使攻击目标在下个回合开始时受到 X 点伤害；此伤害无视任何机制，无法用造成的 X 点伤害再次触发淬毒 |
| 穿透 X | X | 触发 | 攻击时 | 额外对这条线路上的 X 个敌方单位造成伤害；若该线路敌方单位数 < X，则也会对敌方国王造成伤害 |

### 词条中需要裁决的点

- `【待定-B1】` `祝福` / `装甲` / `荆棘` 三者的结算顺序未定义。
- `【待定-B2】` `淬毒`"无视任何机制" 与 `无敌`"无法受到伤害" 直接冲突；`疾病` / `献祭` 的"消灭"不是伤害，因此**可以**消灭无敌单位，需确认。
- `【待定-B3】` `淬毒` / `疾病` 的"下回合开始"是以谁的回合为准？单位已离场时是否落空？
- `【待定-B4】` `淬毒` 多层叠加是否各自结算？
- `【待定-B5】` `暴击` 的额外伤害是否再次触发 `造成伤害:` / `淬毒`？（有无限连锁风险）对国王是否生效？
- `【待定-B6】` `双重打击` + `狂热` 同时拥有时能否连锁出 3 次攻击？
- `【待定-B7】` "额外再攻击一次"时若线路已无敌方单位，是否攻击国王？
- `【待定-B10】` `穿透 X` 的额外伤害**数值未写**（对额外目标造成多少？对国王造成多少？）。
- `【待定-B11】` `溅射 X` 在相邻线路无敌方单位时是否溢出打国王？`穿透` 会溢出、`溅射` 未写，两者不一致。
- `【待定-B12】` `献祭` 被列在"词条"中，但读起来是**动作**而非关键词。它作为词条时如何发动？由谁指定？
- `【待定-B13】` `组合` 的原文两句话互相矛盾，需拆成两条独立规则。
- `【待定-B17】` `飞行` 只给了"条件性两栖"，没有任何"飞"的核心能力，与名称不符。
