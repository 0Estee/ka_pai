# 发行说明 0.70.0

## 新阵营：心驭（控制）

被控制的单位会**打上「被控制」标签、卡面出现粉红色纹路**，并被**搬到控制者那一侧**，
此后算控制者的单位（开战打它原来的队友、能被献祭）。扎根的单位控制不了。

| 卡 | 类型 | 费用 | 效果 |
|---|---|---|---|
| 恶堕の催眠 | 道具性锦囊 | 1 | 控制一名花费≤3的敌人 |
| 绝对の服从 | 道具性锦囊 | 1 | 控制一名攻击力≤2的敌人，召唤一张最强の诱惑 |
| 最强の诱惑 | 道具性锦囊（令） | 7 | 控制一名敌人 |
| 人性の爱 | 攻击性锦囊 | 1 | 选择一个单位，指定另一个单位与其战斗，抽一张牌 |
| 魔醉の臣服 | 道具性锦囊 | 1 | 控制一名敌人并将其冻结，下个回合开始时返回敌方手牌 |

自己定的边界（想改说一声）：

- 控制落地位置：先镜像格（同线路同排）→ 同线路另一排 → 其它线路空位，**地形照旧**；
- 我这边**没有空位**时，这个敌人不会出现在可选目标里（不会白打一张牌）；
- 「与其战斗」是**同时**互砍一次，同归于尽也算双方都出手。
