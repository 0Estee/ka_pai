### 修掉的两个行为缺陷

**1. 小丑「立即进入下个回合」其实把仗打完了。** 旧实现只在「当前阶段已经是 COMBAT」时才跳过开战；
从单位 / 锦囊阶段打出来时，`advance()` 会一步跨进 COMBAT 并当场结算 —— 与「不开战」正好相反。
现在 `endTurnNow` 会**提前看一眼下一阶段**，只要是开战就直接结算回合结束。
新加的测试同时锁住「敌方单位也会额外攻击」和「日志里不该出现 combat-start」。

**2. 活火山扫射时把溅射吞了。** 扫射分支直接 `return`，于是带溅射的活火山只打了一份。
现在扫射之后按通常口径给相邻线路补一份溅射伤害。
