# 0.51.0

## 改动

- 新增卡牌飞行动画：抽到新手牌时，卡牌从屏幕正下方沿弧线飞入手牌卡槽。
- 打出手牌时，卡面从卡槽滑向落点格子；AI 出牌统一从屏幕正上方滑入。
- 落点会闪一下落地提示。
- 动画在独立覆盖层上播放，不受每帧重绘影响；不影响操作、结算与回放。
- 新增门禁 30-card-fx：抽牌从下方进入、我方出牌从卡槽飞出、AI 从上方进入三条路径都有断言。
