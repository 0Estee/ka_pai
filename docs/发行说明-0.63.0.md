# 发行说明 · 0.63.0

> 联机两件事：**创建的房扫不到**、**对手显示成 AI**。

---

## 一、创建的房扫不到

### 公网站点

以前「加入房间」不管在 APK 还是网页都会先跑一次 1.5 秒的局域网 UDP 扫描。
网页版根本没有原生桥，扫描永远是 0 个，于是看起来就是「创建完房间后扫不到」。

现在：

- 网页版（只能公网联机）把入口直接改成 **「输入房间号」**，不再扫描、不再显示「找到 0 个房间」；
- 输入框直接收主机大厅里显示的 6 位房号，也可以粘整条邀请链接；
- APK 的局域网扫描保持原样。

### 局域网（APK）

- 部分机型的 Wi-Fi 栈会过滤广播/多播，导致「HTTP 房间开好了，但对面扫不到」。
  现在扫描和应答期间都会持有 **MulticastLock**（新增 ACCESS_WIFI_STATE /
  CHANGE_WIFI_MULTICAST_STATE 两个普通权限）。
- UDP 应答器起不来时（8766 被占），主机的开房结果会带 discover=0，
  大厅里直接显示「对方扫不到，只能手输地址」，不再让主机以为一切正常。

## 二、对手显示成 AI

- 联机状态条以前写死 你 / AI；现在按座位显示 **玩家1 / 玩家2**；
- 登录了账号的玩家，显示 **账号用户名**（进房 hello 会把自己的名字发给对面）；
- 先手/后手固定为 **玩家1（主机）先手、玩家2（客人）后手**，
  状态条右侧的「先手 / 后手」与座位一致；
- 阶段提示从「AI 行动中」改成「某某 行动中」，不再出现 AI；
- 大厅顶部也显示自己的座位和名字，例如「张三（玩家1 · 主机）」。
