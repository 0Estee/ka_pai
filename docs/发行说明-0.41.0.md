# 0.41.0

## 改动
- 新增第二个阵营「上帝」与 5 张超能力（作者 2026-10-04）：`传教`（选一个格子召唤令牌「上帝的信徒」）、
  `上帝的信徒`（回合开始：所有队友 +2 生命上限，为友方国王回复 2 点血量）、
  `圣经`（一名队友本回合获得无敌并 +2 生命，抽一张牌）、
  `庇佑`（所有友方单位和友方国王本回合获无敌，抽一张牌）、
  `祝福`（使一名队友获得祝福 1，抽一张牌）。
- 召唤改成玩家在场上选落点：`传教` 与 `召唤仪式` 打出后会列出合法格子（地形与身位都算在内），
  玩家点一个格子才落人；延迟召唤在**打出时**就把落点记下来。界面用不遮棋盘的底部条，AI 侧取第一个合法格。
- 「本回合无敌」现在也能作用在国王上（此前只对单位生效）；无视机制的伤害照样被挡。
- 顺手修掉 `data/卡牌表.csv` 里重复的 BOM（0.40.0 起就带着），并更正卡数与测试数：
  158 张卡 / 24 张令牌 / 8 张阵营超能力 / 126 张可入牌库 / 102 个规则测试。
