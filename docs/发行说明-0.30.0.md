## 修好：强化士兵在开战回合选完攻击目标后卡死

- 根因：开战结算推到一半挂起（问「要打谁？」）时，**推进链就停在那一问**；玩家答完（`resolvePlayerChoice`）只重新渲染，没人把 `tick()` 接回去，于是画面永远停在 COMBAT。
- 修法：`app/js/play-input.js` 答完之后补 `if (!session && !state.pending && state.winner === null) tick();`
- 固化成门禁 `tools/checks/20-combat-suspend.mjs`：跑真实回合循环（摆强化士兵 + 靶子 → 推进到挂起 → 点选）→ 断言 pending 清空、阶段离开 COMBAT。

## 修好：开战演出没播完就进入下一回合

- `tick()` 里加了「演出中直接返回」的闸（`view.fx` / `view.fxTimer` / 队列非空时就只渲染、不推进）；演出收尾回调里再接回 `tick()`。
- 同一条门禁断言：采样期间不会出现「还在忙、回合却已经翻页」。

## 打出锦囊或陷阱时的放大展示（2 秒）

- 之前 `flashPlayPresentation` 只在 AI 那一侧调过，**玩家自己出牌走的 `commitPlay` 漏了** → 补上。
- 现在：锦囊使用 / 陷阱触发都在战场上方放大展示 2 秒；陷阱**埋伏**只提示主人（对手只看到「敌方陷阱」，这是裁决 D67 的口径）。

## 飘字动画不再反复触发

- 根因：`refresh()` 会整块重建 `#stage`，任何一次重渲染都会让同一个飘字**重启动画**，看起来像反复触发。
- 修法：飘字播不播由一次战斗步进决定（`fx.animateFloat`），同一个飘字只播一次；步进 620ms → **820ms**，最长动画 0.80s，仍满足「最长动画不超过单步」的不变式。

## 狙击手「自己线上的战斗开始前：造成 2 点伤害」

- 我把各种配置都实测了一遍（自己前排 / 自己后排 / 敌方在前排 / 敌方在后排 / 敌人不在这条线）— **都能正常发动**，对不在这条线的敌人正确地不发动；日志里那 2 点伤害排在 `lane-combat` 之前。
- 这次没改它的实现代码，只加了门禁 `tools/checks/21-combat-start-trigger.mjs` 守住两侧。若手机上仍然不发动，请把**具体场面**告我（哪张卡、在哪条线、谁先手、当时有没有其他光环），我照场面复现。

## 第 3 补给营：「选择一个单位」现在敌我都能选

- 卡面写「一个单位」就敌我都能选：新增 `chosenAnyUnit` 目标类型（`engine/src/targets.js` 与界面 `analyzeSpell` 必须同步登记，否则 `16-target-registry` 门禁会红）。
- 实测：面板选项同时含友方与敌方，选友方后按其词条数抽牌。

## 淬毒可以对国王生效（裁决 D69）

- 之前淬毒只挂单位。现在国王也会中毒：标记记在玩家对象上（`kingMarks`），在**回合开始、费用重置那一刻结算一次**并清空；国王中毒的日志带 `kingSide`，界面飘字照样显示「中毒 X」。
- 疾病仍然只对单位生效（国王不是单位，不会得病）。
