# 0.56.0

## 新增
- 派对阵营（5 张超能力）：
  - 小丑（1 费 1/2 单位）：打出时所有单位额外攻击一次，然后立即进入下个回合
  - 惊喜（1 费 道具性锦囊）：召唤一张随机令牌（费用 -1），友方国王回复 3 点生命
  - 爆炸水果蛋糕（1 费 攻击性锦囊）：对一名敌人造成 6 点伤害，敌方抽一张牌
  - 杂技演员（1 费 1/4 单位）：受到伤害时抽一张牌；被消灭时召唤一张气球
  - 气球（2 费 0/1 令牌，组合）：被消灭时对这条线上的所有敌人和敌方国王造成 3 点伤害
- 与 AI 对战时 AI 的阵营改为随机（原来固定和玩家同阵营）。用局内种子决定，同一局的回放与联机锁步仍然一致。

## 改动
- 新增引擎操作：立即进入下个回合、随机令牌进手牌；AI 估值同步补上，不会拿着新牌不打。
- 难度页阵营列表增加派对；README 的阵营说明同步。
- 门禁适配：AI 阵营随机后，检查只认我方所选阵营，并逐个断言每一方抽到的是自己阵营的超能力。
- 修掉一条假失败：难度加成对账时，若 AI 是炼金阵营，起手那张会被算成一次抽牌（多给一张原料），让 起手多几张 对不上。
