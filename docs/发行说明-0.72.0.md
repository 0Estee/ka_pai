# 发行说明 0.72.0

## 改动

### 融合（改成「带融合的那张算作被消灭」）

作者 2026-10-25 的新口径，取代之前的「队友消失、新牌顶替」。两个方向都成立：

- 把**带融合的牌**打在队友身上 → 队友留在场上，融合牌进弃牌堆；
- 把**普通单位**打在带融合的队友身上 → 新牌留在场上，带融合的那张被消灭。

两点要记住：

- 「被消灭」是**真的被消灭**：触发它自己的「被消灭:」、计入消灭数、也触发国王的
  「友方单位被消灭时」被动（旧口径的「什么都不触发」作废）。
- **融合后效果永远结算在留场的那张牌上**，绝不结算在融合牌身上。
  例：霸王龙的「获得双重打击」= 队友获得双重打击；雪人的「冻结一名敌人」= 以队友为来源结算。

### 精通技能改成五档 28 个（作者 2026-10-24 整表重做）

旧的四档 16 个技能全部作废。新表白 / 绿 / 橙 / 紫 / 彩，档位权重 50 / 30 / 15 / 4.5 / 0.5。

除了攻/血/词条，新技能还用到了四类新能力，引擎这边全部接住：

| 能力 | 例子 |
|---|---|
| 触发式异能 | 富足（打出抽一张）、嗜血（造成伤害回血）、奥义（回合开始 AOE） |
| 单位级开关 | 精准（暴击必中）、残暴（暴击率 65%）、扭曲（攻血对调）、不屈（锦囊伤害 −1）、协作（按队友数减费）、连击（双重打击后再打一次）、会心（第 9 回合起 +20 暴击） |
| 国王被动 | 圣洁（在场时国王获祝福 2）、不灭（在场时国王生命至少为 1） |
| 随机展开 | 全能（随机两个词条 + 等同于词条数的攻击） |
