# 发行说明 · 0.62.0

> **这一版只改外观：把整张界面从「后台面板」换成一张摊开的卡牌桌。**
> 规则、卡牌数值、联机、云存档逻辑一条没动。

---

## 一、为什么改

上一版首页更像一个产品后台：白底反白主按钮、台账式列表、所有东西都排在同一条左边缘。
那不是卡牌游戏该有的样子。

这一版的方向是 **王座桌上的战争**：

- 胡桃木桌面、暗红绒布、黄铜包边；
- 卡牌是实物：卡框、费用宝石、铭牌、攻防角标、内框压线；
- 首页是标题画面：王冠徽记、金色大字、木牌入口，而不是功能列表；
- 所有二级页共用同一套皮革 / 羊皮纸面板，不再像设置页模板。

## 二、具体改动

### 首页

- 新增王冠徽记（四线 + 王冠，纯 CSS 绘制）。
- 标题改为金色渐变衬线大字，配「四线战场 · 王座争夺」小标。
- 主按钮改成黄铜木牌：内高光、底部硬阴影、两颗铆钉；文字居中。
- 四个入口各自是一块木牌，不再挤在同一张大台账里。
- 金币 / 星尘 / 等级 / 战绩统一成黄铜底栏。
- 矮屏（约 780px 以下）自动收紧标题区，保证「开始游戏」在第一屏。

### 对局

- 战场是绒布桌面：径向暗红 + 木纹 + 内阴影。
- 格子是皮革凹槽，可放置格改为黄铜描边 + 静态内环。
- 场上单位是迷你卡牌：名字铭牌、内框压线、属性宝石、绿色血条。
- 手牌是木质卡槽：卡框、费用宝石、居中卡名、攻防角标、描述区。
- 选中卡上浮 + 金色光晕；不可出的卡灰化。
- 状态条、费用水晶、结束阶段按钮统一成黄铜件。

### 二级页 / 云存档 / 管理页

- 设置、难度、联机、回放、云存档、用户管理统一为皮革面板 + 黄铜边。
- 输入框、按钮、分段控件、危险操作全部换成同一套木/铜材质。
- 浅色主题是「羊皮纸桌面」，玻璃主题是「秘银冷光桌面」；
  对局桌面始终保持深色绒布，避免卡面看不清。
