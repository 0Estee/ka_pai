# 0.49.0

## 改动

- 动画不再挂在整页的类上，改为在渲染时把方向写进元素属性：同一屏幕重绘时不再从头重放动画（修开局会卡一下、动画过快）。
- 菜单动画覆盖范围扩大：难度选项、阵营／房间行、回放列表项也都跟着滑入（修进入人机对决没有动画）。
- 开局铺开改成一次性的入场窗口：进入对局后的连续渲染都带摊开标记，不会被建局过程中的重绘掐掉。
