# 0.42.0

可直接覆盖安装 0.41.0（versionCode 43）。

## 新增
- 四大阵营：剑道 / 音乐 / 科学 / 神佑，各 4 张非令牌超能力（剑道与科学各多 1 张令牌），共 18 张新卡（U408~U425）。
- 阵营选择界面每个阵营多一句说明；卡牌表与规则书同步（裁决 D74）。
- 剑道：穿透 2 加攻、召唤「连斩」、按使用次数涨费的令牌、攻击力设为 4 并额外攻击、按场上单位数量结算的万剑归宗。
- 音乐：单体 -2/-2 加移人、3 点伤害加全体 -2/-2、光环式全体 -1/-1、在手牌中响应锦囊目标的「和弦」。
- 科学：回合开始加费与被消灭打同线、锦囊免疫加抽牌、重复上一张锦囊的「克隆」、令牌「新兴研究」（手中卡牌减费 + 出牌随机加成）。
- 神佑：替国王挨打的「神使」（生命最低的顶）、本回合国王受伤 -2 加回血、永久锁 0 攻击的「诅咒」与「神罚」。

## 引擎
- 新能力：按使用次数涨费、按场上敌方单位数量取数、单目标复合多效果、重复上一张锦囊、延迟抽牌、随机二选一、国王被动手牌减费、国王伤害转移与减伤、装甲 +1、攻击力永久锁 0、光环式生命上限削弱、在手牌中的锦囊目标响应。
- 规则回归测试 104 -> 124 个。
