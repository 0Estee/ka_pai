# 0.48.0

按作者反馈调整了菜单切换与开局动画的手感。

## 改动

- 菜单切换动画重做：动画只作用在按钮上，整页不再平移、旧页面也不做整页退场。前进时按钮从右侧逐个滑入，返回时从左侧逐个滑入（方向相反），上一版两屏同时动、看起来画面重叠的问题不再出现。
- 动画放慢并保证播完：按钮滑入 0.42s，逐个延迟最多 0.30s，动画播完之前不会被打断（入场标记 900ms 后才清除）。
- 开局节奏放慢：棋盘从上往下逐行铺开（每行错开 60ms），手牌从下滑入（每张错开 55ms）。
- 手牌横向滚动位置在画面刷新后会保留，不再每次都弹回最前面。
