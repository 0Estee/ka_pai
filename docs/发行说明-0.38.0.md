# 0.38.0 发行说明

## 修复

- 联机对战：对手打出的牌如果要选效果（抉择、指定目标等），现在由对手那台设备来选。本地原先会把选项列出来让人点，谁先点谁说了算，等于替对手做了决定；现在只显示「等待对手选择」，连选项都不列（选项里带着对手的手牌和目标）。答案仍走锁步的 `{ k: 'c' }` 传过来。
- 单机不受影响：没有会话时，这类提问本来就都归本地。

## 改动

- 引擎的每个交互请求都带 `side`（该做主的那一方），界面据此分流；新增一格门禁守住这条（源码级扫描 + 四组运行时对照，含客人侧对称验证）。
