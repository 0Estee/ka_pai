## 修好的问题

### 1. 「AI 对决」被写成了「PI 对决」

- 现象：首页 →「开始游戏」进去，二级菜单上写的是「PI 对决」，难度页标题是「PI 难度」，说明文字里也写「难度主要影响 PI 的决策水平」，联机金币不足的提示写「先去打 PI 赚金币」。
- 根因：`app/js/screens.js` 里有 6 处（4 处玩家可见文案 + 2 处注释）把 AI 写成了 PI。这个拼写从仓库的第一次提交（0.27.0）就存在，而仓库其余地方一直写的是 AI：`README.md:262`、`app/js/play-input.js:378,380`、`app/screens.css:125`、`app/_preview.html:29`、`tools/verify-apk.ps1:182`。
- 修法：`app/js/screens.js` 的 `:39`（注释）、`:59`（菜单文案）、`:92`（难度页标题）、`:94`（难度说明）、`:179`（注释）、`:185`（联机金币不足提示）全部改回 AI，无其它改动。
- 防回归：`tools/checks/02-screen-nav.mjs` 新增两条断言：二级菜单必须渲染出 `>AI 对决</span>`，难度页标题必须是「AI 难度」且整页不得出现 PI 字样。故意把文案改回 PI 再跑门禁，确实红在这两条上（exit 1），改回来即全绿。
