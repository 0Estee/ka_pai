# 0.45.0

## 修复

- **战报里的内部编号没了**：被消灭的单位以前显示成「U401 被消灭」，现在是「白板巨兽 被消灭」。
  消灭、中毒结算、疾病发作、轻灵落水这几类日志都补上了卡名；存档里的老回放只存了编号，
  界面会用卡库把名字还原出来。
- **消灭原因改成中文**：以前括号里印的是 `lethal-damage`、`combat` 这类内部标识，
  现在是「致命伤害」「战斗」「献祭」「轻灵落水」等；遇到没登记过的标识就不显示括号。

## 改动

- **战报每行分三段着色**（作者 2026-10 要求）：
  - 谁：用敌我行色（你 / 对手）并加粗；
  - 干了什么：次级色（放置 / 打出锦囊 / 被消灭 / 受到）；
  - 目标：强调色（卡名、线路与身位、伤害数值）。
- 深色、浅色、玻璃三套主题各配了这两支颜色。
