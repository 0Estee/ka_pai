# 0.39.0

## 改动

- AI 难度「困难」改为：起手多 1 张牌 + 国王生命上限 +6（不再多给费用）。
- AI 难度「噩梦」改为：起手多 1 张牌 + 每回合多 1 费 + 国王生命上限 +8（旧的「起手多 2 张」拿掉）。
- 玻璃主题整体提亮：背景渐变更亮、面板/格子/手牌/单位卡的白度各抬一档、磨砂从 blur(16px) 提到 blur(20px) 并加 brightness(1.12)，四角光斑更亮，另加一层白色柔光。
- README 难度表补实测强度：困难打普通 65.7%，噩梦打普通 90.0%、打困难 83.0%（各 300 局，同侧对照 54.7%）。
- 门禁 09 号改成按新口径对账（困难只加手牌与国王血，只有噩梦加费）。
- 玻璃首页的平均亮度实测 45.4  61.9（同一采样口径，深色首页 23.5 作对照）。
