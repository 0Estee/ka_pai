# 0.58.2

## 修复：作者 2026-10-18 报的三个问题

### 1. 强化加成会出现浮点数

强化是 0.1 一档、锦囊精通减费是 0.25 一档，而 IEEE754 的二进制小数存不下 0.1：

- `0.1 + 0.2 = 0.30000000000000004`
- 卡面 6 血的单位练满 3 次 → `6 + 0.30000000000000004 = 6.300000000000001`
- 再挨几次 1 点伤害 → 界面上出现 `1.2999999999999998`

修法是**在所有写入状态的地方规范化到两位小数**（新增 `engine/src/constants.js` 的 `fixNum`）：

- `setup.js` 的单位落地（强化增量在这里第一次进入实例）
- `damage.js` 的扣血 / 回血 / 国王扣血 / 国王回血 / `debuffMaxHp` / `setUnitStats`
- `stats.js` 的 `buffAtk` / `buffMaxHp` / `lockAtk`
- `board.js` 的重生血量

两位小数足够：强化档位 0.1 / 0.2、精通减费 0.25 / 1 都是它的整数倍。

### 2. 白板测试卡没删干净

`DEMO_CARDS`（W01~W05 / K01~K18 / E01~E03）是引擎自检用的白板卡，
但它们同时也出现在**牌库**和**强化工坊**里，玩家能抽到、也能源强化。

处理方式（不能直接删）：

- 给它们打上 `legacy` 标记；
- `isForgeable()` 排除 `legacy` → 工坊不再列出（从 149 张降到 **126 张**）；
- `buildTestDeck()` 只从 `AUTHOR_CARDS` 里取 → 牌库再也抽不到白板卡；
- `aiForge()` 走同一个 `isForgeable`，AI 也不会再强化白板卡。

**仍然保留在 `TEST_CARD_LIB` 里**，因为 `engine/test/smoke.mjs` 的「基础战斗数学」
基准与老回放的 `cardSetId` 都依赖它们 —— 删掉会让历史回放全部判成「卡牌库已变动」。

### 3. 每次强化 / 精通都会刷新界面，导致回到最上方

`refresh()` 是整块重写 `#stage.innerHTML`，`.screen-body`（`overflow-y: auto`）
换成新节点后 `scrollTop` 自然归零。工坊一屏一百多张卡，点一次强化就弹回顶部。

修法：`refresh()` 拆成「记录滚动位置 → `renderScreen()` → 写回」，
且**只在同一屏内重绘时**还原（换屏时保留上一屏的位置没有意义）。
对局屏不受影响（它本来就有 `handScrollOf` / `restoreHandScroll` 管手牌横向位置）。

- `engine/test/smoke.mjs`：**180 条**全绿。
- `tools/check-bundle.mjs`：**174 项**全绿，新增两条：

    单位落地、扣 1 点、回 1 点、再扣 0.1，四步都断言值是两位小数以内且字符串不超长；
  - 「白板测试卡不再出现在玩家可见的地方（工坊 / 牌库）」——
    断言白板卡仍在 cardLib 且带 `legacy`，但 `isForgeable` 为假、四个种子的牌库都抽不到、工坊列表也列不出。

  工坊 DOM 里 `.fc-name` 出现 0 次白板卡。
- `tools/build-web.mjs`：39 个模块；`tools/build-apk.ps1` 与 `tools/verify-apk.ps1` 全绿。
