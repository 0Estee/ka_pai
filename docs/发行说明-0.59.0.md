# 0.59.0

## 新增：作者 2026-10 提的四条动画 / 操作手感

这一版全部是「看得见」的改动，规则一行没动。

### 1. 受击爪印

单位挨打时，卡面上会出现一组抓痕，一道一道划上去，然后整体淡出。

- 素材是作者给的那张 2048×1366 爪印图，切成 **6 组、共 20 道抓痕**，
  存成 `app/img/claw-<组>-<笔>.png`（160×160，透明底）。
- 20 张**共用同一块画布坐标**，所以把同组的几张 PNG 叠在同一个位置就是完整的爪印，
  按 `claw-N-1`、`claw-N-2` … 的顺序错开 90ms 出现，看起来就是爪子从一边划到另一边。
- 每次受击**随机挑一组**，但不会连续两次挑到同一组（否则看着像没换）。
- 只对「单位挨打」生效；打国王走的是血条那条路（`.sb-king.fx-hit`），爪印画不到血条上。
- 画在 `#fx-layer` 而不是塞进 `.unit` 里：`#stage` 每次重绘都整块换 innerHTML，
  塞进去的节点会被冲掉、动画中途跳掉重来。

### 2. 出手的牌翻面

攻击方的单位出手时，它会整张牌绕 Y 轴翻一圈（0° → 360°），转到背面时露出牌背。

- 项目里没有任何卡背素材，所以牌背是**纯 CSS 画的**（`.unit::after`）：
  中心一枚金色菱点 + 一圈环 + 横条纹底，配色走主题变量，三套主题都跟着变。
- 牌背只在「背面朝观众」的那一小段（动画的 22%~78%）才浮出来，
  正面朝观众时看到的仍是牌面，所以不会闪。
- 翻完回到 0°，还是正面。

### 3. 血量变化与退场都等到动画演完之后

- 挨打时，血盾上的数字和血条**先停在挨打前那一格**，等这一下的特效播完才跳到新数值。
- 被打死的牌**先按正常卡面留在格子里**（连血量都是倒下前那一格，不是 0），
  等它所在那条线路的特效**全部播完**，才播消散动画、再从棋盘上撤掉。
- 以前的时序是「开战当帧就退场」，会出现「血还没掉完、牌先没了」。

### 4. 放置交互改成两步确认

以前选中一张单位牌、点一下格子就直接放出去了，手滑就没了。现在：

1. 选中卡牌 → **所有能放的格子高亮**（绿色描边）；
2. 点一个格子 → **这一格变成金色描边**，提示语写「已选中 山地·前排，再点一次确认放置」；
3. **再点同一个格子**才真的放下去。改点另一个绿格子 = 改选，不会放牌。

三态颜色分开（能放 = 绿、已选 = 金、拖动悬停 = 金），玩家一眼能分清。

### 5. 长按拖动放置

除了点选，也可以直接把牌拖到格子上：

- 按住手牌 **约 260ms** 进入拖动（短按仍然是「选中」）；
- 拖动时手上那张牌变淡（`.dragging`），一张克隆卡跟着手指走；
- **所有能放的格子高亮**，手指正下方那一格描金边；
- 拖到合法格子松手 → **直接放置**；
- 拖到别处松手 → 克隆卡**从当前位置飞回手牌**，并且**保留选中**（玩家可以接着点选，不用重新找牌）。

## 顺带修好的

- 退场残影的血量以前画成 `0`，看着像「0 血还站着」。现在按「倒下前那一格」画。
- 残影在等待期不再是半透明灰（那会让人以为已经死了），
  真正开始消散的那一下才变灰淡出。

## 门禁

- 新增 `tools/checks/36-interaction.mjs`：11 条用例覆盖爪印的三态、翻面关键帧、
  血量延后、退场时序、两步点选、长按拖动、可放区高亮。
- `tools/checks/29-motion.mjs` 的「阵亡接线」用例改成新语义
  （退场排在整段演出之后，而不是开战当帧）。

引擎自检 180 项全绿；打包集成测试 175 项全绿。
