# 0.55.0

## 改动
- 「不可能」难度不再写死一个推演深度：改成按**一整个回合**的时间预算自己爬档（默认最多 6 秒）。
  先进最省的一档，顺便量出这台机器有多快，再按算力大致与「候选数 x 步数」成正比，
  直接跳到预算装得下的最贵那一档；手机上慢就自动少算几档，不会卡死。
  档位只加广、不加深：实测加深是负收益（K24/32 步只有 40.8%，K8/36 步也是 40.8%），
  推演越深，评估函数那点偏差被放大得越厉害。
- 门禁新增一条检查：预算 1ms 时必须停在最省的一档、预算管够必须爬上去、
  写死档位要照办、档位超范围要夹到最后一档。
- README 补上这次扫描的全部数据，以及三条试过没用的改法（调评估权重、加深、
  让推演里的对手也用推演器，最后这条明显更差：K2/6 步 30.0%、K4/8 步 23.3%，还慢 5 到 10 倍）。
  诚实结论：这一档的瓶颈是评估函数、不是算力，时间预算换来的是「更不容易漏算」；
  实测预算给足（默认第 4 档 K24/20 步）打噩梦 48.3%，最省的一档 45.8%，差距在噪声内（各 120 局）。
