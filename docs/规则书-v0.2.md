## 1. 术语表

| 术语 | 定义 |
|---|---|
| 国王 | 每方核心，生命上限 20。生命 ≤ 0 时该方失败 |
| 单位 | 卡牌类型之一。拥有攻击力与生命，进入战场后驻留 |
| 锦囊 | 卡牌类型之一。分道具性锦囊与攻击性锦囊（图标不同）。效果发动后消失 |
| 费用 | 使用卡牌需支付的资源，上限 = 回合数 |
| 线路 | 战场横向 4 路：**山地 → 平地（左） → 平地（右） → 水路** |
| 排 | 战场纵向 5 排：**敌后排 / 敌前排 / 陷阱格 / 我前排 / 我后排** |
| 前排 | 己方靠近战场中央的一排。**可被普通交战命中**，起阻挡作用 |
| 后排 | 己方最外侧的一排。**不会被普通交战命中**，只受 `溅射` / `穿透` 影响 |
| 词条 | 卡面**带下划线**的关键词，规则内建 |
| 弹射 | `【待定-A4】` 规则中未定义，但被 `扎根` / `无敌` 引用 |
| 消灭 | 单位从战场进入弃牌堆 |

### 异能的发动时机标注

| 卡面标注 | 发动时机 |
|---|---|
| `打出:` | 该单位由手中进入战场时 |
| `被消灭:` | 该单位被消灭时 |
| `造成伤害:` | 该单位对其他单位**或国王**造成伤害时（规则已修订，原为"打国王不触发"） |
| `有敌人受到伤害时` | **场上任意**敌方单位受到伤害时（不限于本单位造成的）。不含国王（D21），且自身造成的这点伤害不再连锁（D22） |
| `场上没有队友时` | 持续判断：自己棋盘上没有其他友方单位（D29） |
| （无标注） | 该单位在场期间**始终有效**（静态 / 光环） |

### 两种"给数值"的区别（重要）

| | 永久加成 | 光环 |
|---|---|---|
| 例子 | 吸血鬼「造成伤害:获得+1⚔+1♥」 | 拷问官「-3⚔」、密命王牌「+3⚔」 |
| 写法 | 效果动作 `buffAtk` / `buffMaxHp` | 卡牌定义上的 `auras` 字段 |
| 生效 | 一旦获得就永久写进单位数值 | **读取时**才叠加，条件一变立刻变 |
| 消失 | 不会消失 | 光环来源离场 / 条件不再满足 → **立刻失效** |

界面与伤害计算显示的都是**有效攻击力**（永久值 + 光环修正），所以玩家看到的数字就是实际打出的伤害。

## 2. 共享牌库

**双方共用同一个牌库**，这是本作的核心结构。

- 开局时，**先手抽 5 张、后手抽 4 张**，这 9 张**从共享牌库中取出**。
- 每个回合**开始时**（进入 5 个部分之前），双方各抽 1 张，**后手先抽，先手后抽**。
- 抽牌顺序有意义：共享牌库下，**最后一张牌归谁是需要争夺的**。

**设计后果（需在制卡时遵守）**：
1. 卡牌**不能有阵营归属** —— 双方是同一套牌，卡牌必须是中立的。
2. "我抽到强牌" = "对手少一张强牌"，天然零和、天然对称。
3. 牌库张数是对局时长的直接阀门。

`【待定-A1】` 牌库总张数未定。
`【待定-A2】` 牌库抽空后的判定未定。

## 3. 对战目标

- 双方各有一个国王，**生命上限 20**。
- 国王生命 ≤ 0 时，该方失败，另一方胜利。
- `【待定-A3】` 双方国王同时归零的平局判定未定义。
- `【待定-A5】` 无回合上限，存在无限僵局可能。

## 4. 卡牌

### 4.1 通用
- 卡面**左上角**为卡牌类型：`单位` / `锦囊`。
- 使用任意卡牌都需支付费用（见 §6）。

### 4.2 单位
- 属性：**攻击力**（一次攻击造成的基础伤害）、**生命**。
- 生命 ≤ 0 时该单位被消灭，离开战场，进入弃牌堆。
- 多数单位拥有异能，按 §1 的时机标注发动。
- 词条以下划线标注（总表见 §8）。

### 4.3 锦囊
- `道具性锦囊` 与 `攻击性锦囊`，图标不同。
- 效果发动后消失（进入弃牌堆）。
- `【待定-B1】` 目标选择规则未定义（是否可指定国王？"锦囊免疫"暗示锦囊有指定机制）。

## 5. 战场

### 5.1 布局

```
                山地       平地(左)    平地(右)     水路
  敌方后排   [        ]  [        ]  [        ]  [        ]
  敌方前排   [        ]  [        ]  [        ]  [        ]
  陷阱格     [        ]  [        ]  [        ]  [        ]   ← v0.2 空置
  我方前排   [        ]  [        ]  [        ]  [        ]
  我方后排   [        ]  [        ]  [        ]  [        ]
```

- **4 路 × 4 个单位排 = 16 个单位身位**，另有 4 个陷阱格。
- 中间排（陷阱格）在 v0.2 中**不启用**，仅作为无人区分隔双方。

### 5.2 占位规则

- 每条线路每方**默认只能放置 1 个单位**，放置时**自由选择放在前排或后排**。
- 拥有 `组合` 词条的单位在场时，允许该线路**再放置第 2 个**，占用**另一个排**。
- 因此每条线路每方的上限是：**默认 1 个，有 `组合` 时 2 个（前排 1 + 后排 1）**。

### 5.3 地形限制

| 词条 | 放置限制 |
|---|---|
| （无） | 可放置于 **山地、平地、平地**，**不可放置于水路** |
| `两栖` | 可放置于**任意线路**，包括水路 |
| `水生` | **只能**放置于水路 |

`【已裁决-D63】` **移动遵守同一套地形规则**（作者 2026-09）：非水生、无两栖的单位
**不能被移进水路**；水生单位（无两栖）**不能被移出水路**。放置与移动复用同一个判定，
所以「捕猎」和 `move` op 两条路径行为一致。
（取代旧的 `【待定-B2】`。）

## 6. 费用

- 费用上限随回合数增长：**第 N 回合上限 = N**。
- 部分卡牌可增长费用上限。
- **回合开始时，将当前费用设为费用上限**（不结转）。
- 花费 > 剩余费用时该卡牌无法使用。
- 费用在 5 个部分之间**共享**：整个回合共用一个费用池。
- `【待定-B3】` "费用上限增长"是永久还是仅本回合？增长时是否立刻补满当前费用？

> ⚠️ **平衡提示**：第 1 回合费用上限为 1，而放置与锦囊共享，因此**第 1 回合每位玩家只能打出 1 张 1 费牌**，锦囊阶段完全空转。

## 7. 回合流程

一个回合 = 双方各操作一遍 + 开战。共 **6 个部分**：

| 序号 | 部分 | 内容 | 阶段限制 |
|---|---|---|---|
| 0 | **抽牌** | 双方各抽 1 张，**后手先抽** | 共享牌库 |
| 1 | 先手放置单位 | 先手放置单位并支付费用 | 不可打出锦囊 |
| 2 | 后手放置单位 | 后手放置单位并支付费用 | 不可打出锦囊 |
| 3 | 先手打出锦囊 | 先手打出锦囊 | 不可打出单位 |
| 4 | 后手打出锦囊 | 后手打出锦囊 | 不可打出单位 |
| 5 | 开战 | 按山地 → 平地(左) → 平地(右) → 水路依次结算 | — |

- 费用在部分 1~4 之间共享（见 §6）。

## 8. 开战结算

### 8.1 结算顺序

```
for 线路 in [山地, 平地(左), 平地(右), 水路]:
    同时结算该线路上双方的全部单位（前排 + 后排）
```

- **线路之间**：按 山地 → 平地(左) → 平地(右) → 水路 **依次**结算。
- **同一线路内**：双方全部单位**同时**造成伤害。
- ⚠️ 依次结算意味着先结算线路的 `溅射` 可以打死尚未结算线路的单位，这是**有意的信息不对称**。

### 8.2 攻击目标的优先级

每个单位（不论前排还是后排）在开战时发起 **1 次攻击**，按以下优先级选择目标：

1. 若同一线路上存在**敌方前排单位** → 攻击敌方前排单位
2. 否则若存在**敌方后排单位** → 攻击敌方后排单位
3. 否则 → 攻击**敌方国王**

即交战目标优先级为 **前排 → 后排 → 国王**。
前排是掩护：前排还在时后排不会被普通交战命中；前排一清空，后排立刻暴露。
`溅射` / `穿透` 不受此限制，在前排还在时也能打到后排。

### 8.3 位置的意义

| | 前排 | 后排 |
|---|---|---|
| 能攻击 | ✅ | ✅ |
| 被普通交战命中 | ✅ | ❌ |
| 被 `溅射` / `穿透` 命中 | ✅ | ✅ |
| 战术定位 | **阻挡位**：拦住敌方前排，保护国王 | **安全输出位**：不会被普通攻击碰到，但漏防 |

- 若我方线路**前排为空**，敌方前排将直接攻击我方国王（其无法命中我方后排）。
- 因此**纯后排阵容会完全漏防**，这是后排的代价。

### 8.4 未定项

- `【待定-A6】` 多单位配对：我方同线有前排 + 后排（`组合`）共 2 个单位，敌方只有 1 个前排时，两个单位**都**攻击该前排，还是只有前排与之配对？
- `【待定-A7】` 攻击力为 0 的单位的处理（不攻击，是否仍阻挡？是否算"有效的敌方单位"？）
- `【待定-B4】` `溅射` / `穿透` 是否也能命中敌方**后排**（按 D6 应当可以，需确认伤害数值）。
- `【待定-B5】` "额外攻击"（`双重打击` / `狂热`）时若前线已清空，是否攻击国王，还是可以转而攻击后排？

### 回合示例（第 1 回合，费用上限 1）

**抽牌（部分 0）**：后手先抽 1 张（手牌 5），先手抽 1 张（手牌 6）。共享牌库 -2。

**部分 1**：先手花 1 费打出 `1费 1/2` 单位，放在**山地 / 前排**。费用归 0。

**部分 2**：后手花 1 费打出 `1费 2/1` 单位，放在**水路**（该单位须有 `水生` 或 `两栖`；若没有则改放平地 / 前排）。费用归 0。

**部分 3、4**：双方费用均为 0，锦囊阶段空转。

**部分 5 开战**（按山地 → 平地左 → 平地右 → 水路）：
- **山地**：先手前排有单位，敌方前排为空 → 先手单位攻击后手**国王 1 点**。
- **平地(左)**：空场，无事发生。
- **平地(右)**：空场，无事发生。
- **水路**：后手前排有单位，先手前排为空 → 后手单位攻击先手**国王 2 点**。

**结算后**：先手国王 18，后手国王 19。

| 穿透 X | X | 触发 | 攻击时 | 额外对这条线路上的 X 个敌方单位（**含后排**）造成伤害；若不足 X 个，则也对敌方国王造成伤害 |
| 先制 | — | 静态 | 开战时 | 本单位的伤害先于同线路其他单位结算；被它打死的敌人当回合不反击。每回合仍然只攻击一次（卡面写作「这张牌在开战时优先攻击」） |
| 冻结 | — | 静态（状态） | 持续 | 被冻结的单位下一次攻击时**不进行此次攻击**，然后解除冻结。**状态型**，不是印在卡面上的词条；重复冻结不叠加；只有本来会攻击（⚔>0）的单位才会消耗掉标记 |
| 捕猎 | — | 触发 | 有敌方单位被打出时 | 若可能，移动到那个敌方单位所在的线路。多个捕猎单位按 **山地→水路** 的优先级依次移动；`扎根` 的单位不会被移动 |
| 必中 | — | 静态 | 攻击时 | 忽略敌方单位的阻挡，**仅攻击国王**，且这次伤害不可被免疫（连 `无敌` 也挡不住）。该单位身上的 `溅射` / `穿透` 不再结算 |
| 复生 | — | 触发 | 被消灭后 | 在**原处回满血**复活一次，并失去 `复生`。复活**不触发**「被消灭:」异能，也不触发国王的「友方单位被消灭时」被动，不触发打出效果 |
| 融合进化 | — | 静态（打出限制） | 打出时 | 可以在**一个友方单位现在的位置**上打出：那个单位**「消失」**（不触发任何被消灭效果），新单位顶替它的位置。可以带「只有因融合进化打出才发动」的奖励效果 |
| 无法攻击 | — | 静态 | 持续 | 开战时**不出手**；即使攻击力被加成正数也不攻击（与「攻击力为 0」不是一回事） |
| 陷阱 | — | 静态（标记） | 持续 | 标记这张牌属于埋伏/反制型，具体效果按卡面文字结算（「反应装甲」） |

> **卡面符号**：`⚔` 与 `◈` **都表示攻击力**，`♥` 表示生命。
> 卡面可能把 `轻灵` 写成旧名 **`飞行`**，是同一个词条。
> 卡面类型下方带 **「令」** 的卡是**令牌**：不进牌库，只能被特定卡牌召唤到场上或手牌。
> 「召唤」二字**带下划线**＝加入手牌；**不带下划线**＝在场上选一个位置免费打出。
