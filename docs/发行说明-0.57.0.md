# 0.57.0

## 新增：炎帝阵营（作者 2026-10-12 的第五批超能力，U467~U477）

- **异火堆**：阵营为炎帝时开局有 10 张异火（五种各 2 张，全是令牌锦囊）。异火**只能靠超能力的效果获得**，
  并且**抽完不会自动补**；手牌区显示「异火 N」。
- **佛怒火莲 U477**：异火堆和手牌中都没有异火牌时入手；判定在**打出异火之后**做，不会重复入手，
  只有异火堆被重置后才可能再入手一次。
- 11 张牌全部落地：陨落心炎 U467、骨灵冷火 U468、净莲妖火 U469（国王下次伤害为 0 + 回 3 点）、
  生灵之焱 U470（陷阱：国王受致命伤时免伤、回 3 点、弃一张手牌）、三千焱炎火 U471（队友本回合无敌）、
  焰分噬浪尺 U472（**选两条相邻线路**各 2 点 + 灼烧 1 + 拿六合游身尺）、大天造化掌 U473（抉择）、
  焚决 U474（国王：有单位被消灭时抽一张异火）、天火三玄变 U475（抉择，并抽一张异火）、
  六合游身尺 U476（本回合所有单位攻击力为 0）、佛怒火莲 U477。
- **灼烧 1**：造成大于 0 的伤害时，给受伤单位挂上「回合开始时受 1 点伤害」的标记，结算一次即消费。
- 难度页与联机大厅的阵营列表新增炎帝（共 12 个阵营）。

## 其他改动

- 派对**小丑**发动效果后**不开战，直接进入下一回合**（作者裁定）。
- 修复：国王的「有单位被消灭时」效果只看被消灭那一方，导致炎帝「焚决」在**敌方**单位被消灭时不触发。
- 修复：`endTurnNow` 会跑完整个回合阶段（含开战），与「立即进入下个回合」的口径冲突。

## 门禁与测试

- 打包产物集成测试新增炎帝阵营检查（阵营可选、11 张牌与令牌标记、异火堆 10 张与界面张数、抽空不自动补、整局自走能终局）。
- 规则测试新增炎帝一组 18 条，共 **180 条**全绿。
