# 0.58.1

## 改动：强化独立成一个模式（作者 2026-10-17 口径）

上一版把强化 / 精通直接叠在普通对局上：任何一局都会读玩家的 `profile.forge`，
AI 也按难度随机强化。作者这次明确：**强化是单独一个模式，和普通模式分开。**

- **首页**新增「强化模式」入口，与「开始游戏」并列。
- **普通模式**（开始游戏 → AI 对决 / 局域网对决）：**完全不读强化 / 精通**，
  双方都是卡面原值；AI 也不会被强化。普通模式的平衡数据不再被成长系统污染。
- **强化模式**（强化模式 → 强化 AI 对决 / 强化 联机对决 / 强化工坊）：
  只有从这里的对局才把档案增量交给引擎；AI 按难度强化（0 / 15% / 35% / 60% / 85%），
  联机时双方各带自己的强化卡组。
- **强化工坊**从普通模式的二级菜单里移走，只挂在强化模式下面。
- 模式跟着「再来一局」走：从强化模式开的局重开仍在强化模式，普通模式同理。
- **联机**以主机为准：模式随开局参数一起广播（`Session.beginGame` 的 `mode`），
  客人按收到的模式重设本地状态；大厅会显示房间模式与对手模式，不一致时明确提示
  「开局以主机为准」。
- 回放：普通模式的录制里 `enhance = null`，强化模式带着双方的增量表，两种回放各自复现。
