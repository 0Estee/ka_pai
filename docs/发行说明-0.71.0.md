# 发行说明 0.71.0

> 这一版只加一件事：**「不可能」难度看得到你的手牌，也看得到双方下一次各抽到什么**。
> 对局规则、卡牌、联机协议都没动；它的**数值**依旧完全不加（手牌张数、费用、国王血量和玩家一样）。

## 它现在知道什么

| 它知道什么 | 用在哪 |
|---|---|
| **你手里的每一张牌** | 下单位时避开正好会被解掉的落点（血少的前排会绕开你的直伤范围）；你手里压着斩杀时改去堵空门；解牌该现在打还是留着 |
| **双方下一次各抽到什么** | 评估局面时把「下一抽」算进去（自己抽到好牌 vs 你抽到好牌） |

实现在 `app/js/ai.js`，一组**纯读**的小函数：`insightOn` / `cardHandValue` /
`removalInHand` / `kingDamageInHand` / `nextDrawCard` / `handValue` /
`incomingThreat` / `myBurst`，接在四个决策点上：

- `scoreUnitPlacement`：落点评分（会被解掉的落点 −2.4、硬解在场时脆弱身材再 −1.4；对面能斩杀时前排堵空门加分）；
- `scoreSpell`：解场牌在对面有斩杀时优先打出去；
- `bestSpellTarget`：自己这回合能斩杀时优先打脸；强化目标避开对面手里正好能解的单位；
- `evalPosition`：局面分里加上「手牌总价值差」与「下一抽价值差」。

三条纪律和推演同一套：**只读**（不写 state、不推 rng、不改牌序 —— 否则回放与联机锁步会崩）、
只在 `P.insight` 打开时生效、全部走函数参数不做全局状态。

## 界面上怎么说的

选难度页「不可能」那一行多出一行小字：

> 信息优势：看得到你的手牌 · 看得到双方下一次各抽到什么

底下那句总说明也改了：以前写「不可能不加任何优势」，现在写
「**不会多一张牌、多一费、多一点血**，但它看得到你的手牌和双方下一次各抽到什么，还会真的推演后面几步」。
—— 优势照旧逐条写明，不偷偷作弊。

## 诚实结论：它没有变强，只是「看得见」

`n=240` 双向对照（开信息优势 / 关信息优势各占一侧，种子 1 与 501）：**开 243 / 关 236 / 平 1 = 50.7%**，
在噪声里。这一档的瓶颈还是评估函数，不是信息。

但**决策确实变了**：写死种子跑同一批局面，**11.6% 的决策点会打出不同的牌**
（早先只在 `evalPosition` 里加一项时只有 4.4%）。

试过但没用的（都记在 README 里，免得下次重走）：

| 改法 | 结果 |
|---|---|
| 只把「手牌价值 / 下一抽价值」的权重调大（`wHandValue` 5 / 20 / 60） | 决策分歧升到 18%~22%，但**胜率反而降**（`w60` 组比基线少 15 个胜场，`n=120`） |
| 用信息优势调**留手判定**的 margin（−6 / −1.5，温和版 −2.5 / −1.2） | 两次都崩：49.6% 与 38.9%（对照 60.0% / 52.1%）。留手判定是这一档实测最强的一环，一行都不动 |

## 门禁

| 门禁 | 结果 |
|---|---|
| `engine/test/smoke.mjs` | ✅ 192 |
| `tools/check-bundle.mjs` | ✅ 274（新增 4 条） |
| `tools/verify-apk.ps1` | ✅ |

新增的 4 条都在 `tools/checks/09-ai-difficulty.mjs`：

1. **信息优势只开在这一档**，并且逐条写在选难度界面上（其它四档 `insight` 必须为空；`bonus` 仍是 `null`）；
2. **`nextDrawCard` 的口径与引擎真实抽牌一致** —— 跑几轮真抽牌逐张对账（抽牌顺序哪天改了这条先炸）；
3. **那组函数是只读的** —— 牌序 / rng 状态 / 双方手牌指纹调前调后必须一模一样；
4. **关掉 `insight` 会真的改变决策**（不是摆设），且默认开着 —— 用可复现的分歧率，不用胜率（胜率在噪声里，做门禁只会得到随机失败）。
