# 0.58.0

## 新增：强化工坊（作者 2026-10-16 需求）

开始游戏菜单里多了一档 **强化工坊**（`screen = 'forge'`），卡池按首字母分组排开，
可以切成「按类型」（基础牌 / 锦囊牌）两组。金币、星尘、表现分都显示在页头，
「10 金 → 1 星尘」的兑换按钮也在这一行。

### 强化

- **基础牌**（单位）：每强化一次 **+0.1 攻击、+0.1 生命**，第 9 次一次 **+0.2**，
  九次合计 **+1.0 攻 / +1.0 血**。费用 `12 + 4n`（第 1 次 12 金 … 第 9 次 44 金，共 **252 金**）。
- **锦囊牌**：同样能强化 9 次、同样计费，但**数值不变** —— 九次强化只是「获得精通的资格」。
- 强化是**永久**的，记录在存档 `profile.forge` 里；对局开始时由 `startNewGame` 交给引擎
  （`state.enhance[side][cardId]` = { atk, hp }），回放也带着同一份增量，所以回放能逐帧复现。

### 精通

- **基础牌精通**：可以选择「交出前面强化得到的数值」，换取**永久技能**。
  技能从 **白 / 绿 / 金 / 彩** 四档里抽（权重 50 / 30 / 15 / 5，效果依次增强），
  每次抽 **3 个**给玩家三选一。每张牌最多精通 **2 次**，第 2 次消耗星尘翻倍（20 → 40）。
- **锦囊精通**：每次 **−1 费**（原费 ≤2 的牌每次只 −0.25），最多 2 次。
- **洗精通**：基础牌不满意可以把这一次精通洗掉（星尘不退），洗完要把**强化重新练 9 次**才能再精通。

### 星尘（新货币）

- 初始 **60**，上限 **500**；金币上限改为 **1000**，超出部分按 **10 金 → 1 尘**自动折算。
- 来源：对局结算（胜 8 / 平 5 / 负 3，联机 ×2）、金币溢出、工坊里的手动兑换。
- 等级不再看金币：改看 **表现分 perf**（胜 100 / 平 60 / 负 30，每剩 1 点国王血 +2（≤40），
  8 回合内取胜 +40，每击杀 +10（≤50），联机 ×1.5），曲线仍是 `200n + 25n(n-1)`。

### AI 与联机

- **AI 对决**：按难度决定它自己牌组的强化/精通程度 —— 简单 0、普通 15%、困难 35%、
  噩梦 60%、不可能 85%，且**不消耗对局 rng**（同种子结果完全一致，锁步与回放不受影响）。
- **联机对决**：双方各自带着自己存档里的强化/精通进场，互不覆盖；锁步校验里也带上了这份增量。
- 结算浮层新增星尘 / 表现分 / 等级三段小结。

## 其他改动

- `tools/gen-pinyin.py` 原来只扫 `engine/cards/test-cards.js`，现在遍历 `engine/cards/*.js`；
  重新生成后 `app/js/pinyin.js` 从大量首字落到「#」组变成正确归组（霸王龙/宝藏/绷带/病源体 → b，
  沧龙/苍耳/缠绕水草 → c）。工坊和卡表的分组因此是对的。
- `tools/verify-apk.ps1` 的 `Get-ProbeTitle`：PowerShell 5.1 按 `[Console]::OutputEncoding`（默认 GBK）
  解码原生程序的 stdout，而 Chrome 的 `--dump-dom` 是 UTF-8 —— 三条中文标题断言永远不相等。
  现在在调用前后临时把输出编码切成 UTF-8（不写 BOM）并恢复，`verify-apk` 在 5.1 下也能跑绿。
  **注意：这个脚本必须保留 UTF-8 BOM**，用会去 BOM 的编辑器改完要补回来，否则 5.1 按 ANSI 解析直接语法错。
- `tools/check-bundle.mjs` 的 `lockstepCheck` 里 `makeRec()` 补传 `enhance`：强化是建局参数，
  漏传会让「按种子遍历 14 局」有 9 局分叉（报 `手牌中没有 iid=28` 一类）。
- 五个按卡面数值断言的老用例（`17-combat-target` / `19-combat-fx` / `21-combat-start-trigger` /
  `22-spell-banner` / `29-motion`）统一先 `setDifficulty('easy')`（简单难度不强化），
  消除 AI 随机强化带来的间歇失败。
- README 的结构树、模块数（36 → 39）、导航图与「金币、星尘与等级」「强化与精通」两节已同步。
