# 0.43.0 发行说明

可直接覆盖安装 0.42.0（versionCode 44）。

## 修复

- 联机认输：以前一边点认输只在本机改胜者，对手那边不结算、也不显示胜利。现在认输是一条引擎操作，走锁步发给对方，两端一起结算。
- 联机阵营：以前联机只能被主机安排阵营（两边都是主机的），大厅里选不了。现在主机和客人都能在房间里选自己的阵营，开局把两边的阵营一起下发。
- AI 补刀：AI 侧遇到「选一个敌方单位」的效果（例如狙击手开战时那一下）以前固定取第一个目标，现在优先打生命最低的。

## 其他

- 认输的终局文案改成两端一致的中性文案（锁步会逐字节比对状态）。
- 规则回归测试从 124 个增加到 126 个：新增认输语义、AI 补刀两条。
- 打包集成测试新增三条：AI 补刀、联机大厅阵营选项、联机认输走操作并锁步一致。
