# 发行说明 · 0.60.1

> **这一版只修 bug，规则一条没动。**
>
> 三个问题：联机开局出不了牌、没有友军也能献祭、长按拖动的手感全错。
> 前两个是逻辑漏判，第三个是手势与尺寸，都补了能挡住复发的门禁。

## 一、联机开始后无法出牌

**现象**：两边都点了「开始对战」，棋盘正常显示，但怎么也点不动牌；
阶段一直卡在「回合开始…」。

**根因**：不是联机同步，是**回合循环根本没启动**。
单机开局走 `newGame()`，那里会清掉回合循环的定时器并复位防重入标志
`autoAdvancing`；联机开局走的是 `lan.js` 的 `onStart`，**从来没做这份清理**。

于是只要上一局是在自动阶段（回合开始 / 开战 / 结算）被退出的，
`autoAdvancing` 就停在 `true`；新对局 `tick()` 第一段就撞上
`if (autoAdvancing) return;` 直接返回 —— 阶段永远停在 `TURN_START`、
`busy` 恒为 `true`，而 `selectCard()` 第一行就被 `busy` 挡掉。

**修法**：

- 抽出 `resetTurnLoop()`（定时器 + `autoAdvancing`），
  `newGame` / 联机开局 / `goHome` / `quitRoom` 四条路径都调它；
- 开局逻辑抽成 `beginLanMatch()`，主机客人共用同一条；
- 顺带加固：传输层请求加 12s 超时，操作广播最多等 3s（操作照发），
  网络慢不再能把整个回合循环拖停。

## 二、恶魔阵营在场上没有友军的情况下也可以献祭

**根因**：卡牌「死神」U401 的「献祭一名队友」选项是**死列表**。
空场也能选中它：`sacrifice` 解析不到目标被静默跳过（不报错），
但这条分支**后面的效果照常结算** —— 白拿 +1/+1、自己的国王照掉 3 血、
对敌 5 点伤害照打。

**修法**：

- 引擎：`choose` 的选项支持 `if` 前提，条件不成立就**不出现在面板里**、
  也不执行；新增 `ownUnitsGE` / `foeUnitsGE` 两个条件（支持 `excludeSource`）；
- 死神 U401 的献祭分支加前提 `ownUnitsGE(1, excludeSource: true)`；
- 界面：献祭按钮以前只看「有没有选过阵营」（所以炼金、上帝也有），
  现在限定 `faction === 'demon'`。

> 结论写进了 `data/_transcribe/引擎DSL速查.md` 的「选项的前提」一节：
> **凡是「先付代价再拿好处」的选项，代价付不出来时都要写 `if`。**

## 三、长按拖动的三个手感问题

| 现象 | 根因 |
| --- | --- |
| 拖动时克隆卡摊成一条通屏宽的长条 | `.fx-drag-card` 没有确定尺寸，里面那层 `.card` 是 `width/height:100%`；绝对定位父元素宽度为 `auto`，百分比退回到包含块（整块 `#fx-layer`）解析 |
| 刚开始动，牌自己就落位了 | `pointercancel`（滚动抢手势 / 来电 / 切后台）和 `pointerup` 走同一条路，被取消那一刻手指正压在高亮格子上就会 `commitPlay` |
| 拖到错处，提示也说错 | 三种错法都报「没放到格子上，牌已飞回手牌」，而且**并没有飞回去**（只把克隆卡删掉） |

**修法**：

- 克隆卡按**源卡实测像素**绘制（`getBoundingClientRect` → `width/height`），
  样式里也补了确定尺寸兜底；
- 新增 `abortCardDrag()`：手势被系统取消时只清现场、不放置、不写失败提示；
- 手牌区加 `touch-action: pan-x` —— 横向仍可滑动手牌，纵向手势留给拖动；
- 拖动失败一律走「飞回手牌」，提示按错法分开说：
  压到敌方那侧 / 这个格子放不下 / 压根没压到格子。
