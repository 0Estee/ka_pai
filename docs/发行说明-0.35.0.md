# 王座交锋 0.35.0

游戏正式定名「王座交锋」（原名「卡牌对战原型」）。桌面图标、安装列表、首页标题、页面标题都换过来了。

## 修复（作者 2026-10 报的三条）
- 敌方使用锦囊时没有提示：AI 出牌走的是一条单独的代码路径，现在也会放大展示卡名与效果（2 秒）。
- 提示重复弹出：横幅的入场动画改成只在第一次渲染时播一次，同一次操作里的重渲染不会又弹一遍；陷阱触发的横幅也不会在之后的每一次推进里重复出现（以前会一直重复到那条日志离开窗口）。
- 单位被消灭的结算时机：阵亡单位先留一个淡化的残影，等它所在线路的动画演完才消失（以前棋盘第一步就少了那个单位，飘字只能落在空格子上）。
