## 修好：致命打击答完第二段后被自动结束回合

- 现象：3 费锦囊「致命打击」对敌方国王造成 3 点后，第二段还要「选择一个敌方单位」（生命上限 -3）；答完这一问，回合被直接结束。
- 根因：0.30.0 为修「强化士兵卡死」在 `app/js/play-input.js` 答完选择后补了一句 `tick()`。它本意只是把**自动阶段**（开战结算）接回回合循环，但玩家自己的行动阶段也会走到它；而玩家阶段有个兜底：`G.getLegalPlays` 为空就 900ms 后自动结束阶段。致命打击花光 3 费后手牌里通常没有别的可出，于是被这句 `tick()` 立刻判成「没牌可出」，把回合结束掉了。
- 修法：那句 `tick()` 只在该阶段的主控不是玩家时才执行：`if (!session && !state.pending && state.winner === null && G.getActor(state) === null) tick();`。玩家自己的阶段继续停在界面上等操作（想结束就按「结束回合」）；强化士兵那条修复不受影响（门禁 20 仍绿）。

## 改口径：狙击手「开战时:造成2点伤害（选择一个目标）」（裁决 D71）

- 原文「自己线上的战斗开始前:造成2点伤害」打的是**该线路敌方全体**；作者 2026-10 改成开战时造成 2 点伤害，并**选择一个目标**。
- 目标口径沿用 D16：敌方任意单位**或敌方国王**。
- 真人自己的那一侧：开战时**挂起面板**问「打谁」（请求带 `noAuto: true`，走强化士兵同一条挂起协议 D55）；AI 那一侧仍由引擎自动取第一个选项。
- 触发时机不变（`onCombatStart`，逐线路；一个单位只属于一条线，所以一次开战只问一次），这 2 点仍排在该线路 `lane-combat` 之前。
- 实现：新增选择器开关 `askHuman: true`（`engine/src/targets.js` 的 `askHumanFor`，判据用 `state.humanSide`，**不是** `autoResolveChoices`，见 D71）。目前只有狙击手用它；其它真人侧触发式点选（淬毒蜘蛛 / 红火蚁 / 水蛭）不动。
- 门禁 `tools/checks/21-combat-start-trigger.mjs` 重写为两条：真人侧「挂起点选 + 只打选中的那一个 + 早于 lane-combat + 答完之后结算链继续跑完」；AI 侧「不挂起，照样在 lane-combat 之前打 2 点」。

## 顺带修掉：开战结算里「触发异能要问人」会先打完再弹面板（引擎缺陷）

- 根因：`engine/src/combat.js` 的 `runCombat` 清触发队列用的是同步版 `flushTriggers(state)`（没有 `yield*`）。触发异能内部挂起时返回的 PENDING 被丢掉，循环继续把该线路结算完，于是出现「人都打完了，面板才弹出来」，而且玩家答完也接不回后面的结算。
- 修法：新增 generator 版 `flushTriggersGen(state)`（`engine/src/choices.js`），`runCombat` 改用 `yield* flushTriggersGen(state)`；PENDING 一路传到最外层，`state.pending.gen` 就是整条 `runCombat`，玩家答完由 `resolveChoice` 把剩下的结算驱动完。同步版 `flushTriggers` 改成 `driveGenerator(state, flushTriggersGen(state))`，行为不变（其余调用点未动）。
