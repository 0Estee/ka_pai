# 发行说明 · 0.61.0

> **这一版加了账号与云存档**：用户名 + 密码登录，进度存到 Cloudflare；
> 管理员可以看用户数据、重置密码、删号。
>
> 注意：**代码与测试已完成，但 Cloudflare 还没部署**（这个容器里没有
> wrangler 登录态）。上线步骤见 `docs/公网联机部署.md` §8。

---

## 一、玩家侧

- 首页「更多入口」新增 **云存档**；设置页也有同一个入口。
- 第一次用点「注册新账号」，用户名 2~20 字符（中文 / 字母 / 数字 / 下划线），
  密码 6~128 位；之后用同一组用户名密码登录。
- 登录后：
  - 云端没有存档 → 自动把本机进度传上去；
  - 本机是空档 → 自动载入云端；
  - 两边都有进度 → **不自动覆盖**，账户页里二选一「用云端 / 用本地」。
- 本地存档改动后 2 秒防抖自动上传；也可以手动「上传本地 / 拉取云端」。
- **只同步金币、星尘、表现分、战绩与强化进度；回放仍只保留在本机。**

## 二、管理员

- 默认管理员：用户名 **123**，密码 **1145145**（首次初始化自动创建）。
- 管理员登录后，账户页出现「用户管理」：
  - 用户列表（角色、局数 / 胜场 / 表现分 / 金币、存档版本与大小、上次登录）；
  - 重置某个用户的密码（该用户所有设备立即失效）；
  - 删除用户（连带云端存档；不能删自己）。
- 密码只存 PBKDF2-SHA256 哈希（16 字节盐，默认 10 万次），
  客户端任何地方都没有管理员口令；管理接口服务端会再验一次 role。
- **默认密码是用户指定的弱口令，部署后必须立刻换掉**：
  ```bash
  npx wrangler secret put ADMIN_PASSWORD
  ```
  也建议配 `AUTH_SECRET`。

## 三、实现

### 服务端

- 新增 `Users` Durable Object（`cloudflare/src/users.js`，全站单实例 `global`）：
  注册 / 登录 / me / 改密、存档 GET/PUT（带 baseVersion 冲突检测）、
  管理员列表 / 重置密码 / 删号、CORS、登录失败锁定。
- `cloudflare/src/room.js` 在房间路由之前拦 `/api/auth/*`、`/api/save`、
  `/api/admin/*`，转给 `env.USERS`。
- `wrangler.toml` 增加 `USERS` 绑定与 v2 migration；v1 Room 原样保留。
- token 是无状态 HMAC-SHA256（30 天），密钥优先 `AUTH_SECRET`，否则在 DO 存储里
  首次生成并持久化；改密 / 重置会把 tokenVersion +1，旧 token 立即失效。

### 客户端

- 新模块 `app/js/cloud.js`：登录态、请求、防抖上传、冲突、管理员数据。
- 新页面 `account` / `admin`（`app/js/screens.js` + `app/screens.css`）。
- `Store` 增加云登录态读写与「本地保存后回调」钩子；`app-state` 增加 `setProfile`。
- APK 从 `file://` 加载时走 `https://www.wangzuo.icu/api`；
  网页端同源 `/api`。

## 五、部署（必须做）

1. `cd cloudflare && npx wrangler deploy --dry-run` 看配置；
2. `npx wrangler deploy` 应用 v2 migration（v1 不要删）；
3. `npx wrangler secret put ADMIN_PASSWORD` 换掉默认管理员口令；
4. 可选 `npx wrangler secret put AUTH_SECRET`；
5. 部署后打开线上站点，注册一个普通账号，确认能登录、能同步；
6. 管理员用 `123 / 1145145`（或新口令）登录，确认用户管理页能列出刚才的账号。
