# 0.36.0 发行说明

界面改版：纸质卡牌风格（作者 2026-10 选定）

## 改动

- 两套主题都重做：深色 = 深色木桌 + 深羊皮纸卡；浅色 = 米白纸桌 + 白纸卡。设置里切浅色/深色都能看到新风格。
- 去掉全部发光效果（单位选中、可放置格、目标脉冲、金币、首页标题的金光），改成实线内框、纸片偏移阴影与方角。
- 圆角统一收小到 3~5px；标题、横幅、阶段名改用衬线字体，正文仍是系统无衬线字体。
- 修掉几处在浅色主题下会看不见的颜色：抉择面板的遮罩与选项底色、联机房间/服务器输入框、破产提示，改成跟随主题变量。
- 只改 app/style.css 与 app/screens.css，游戏逻辑与界面结构未动。
