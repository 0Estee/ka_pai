# 王座交锋 0.37.0

新增第三个外观选项「玻璃」，设置里可切换（设置 -> 外观）。深色与浅色（纸质卡牌风）都保留。

## 玻璃主题做了什么

- 大面板走磨砂玻璃：`backdrop-filter: blur(16px) saturate(1.5)` + 高光上边（顶栏、状态条、手牌区、菜单、设置、结算、提示条、横幅、抉择框、卡牌详情）。
- 棋盘格子、单位、手牌不加背景模糊（20 个格子会拖垮手机 GPU），它们靠半透明底色和圆角做出玻璃感。
- 背景是固定不滚动的渐变光斑（三团冷色光 + 深色渐变），面板半透明才看得见它。
- 圆角从纸质的 3~5px 回到 12~16px；金币改成一颗玻璃珠；首页标题加冷色柔光。
- 玻璃主题的标题走系统无衬线，纸质主题仍走衬线，两套观感分得开。

## 实现与兼容

- 主题白名单（`app/js/render.js`）接受 `glass`，认不出的取值仍回落到深色；设置页三个选项共用同一个 `set-theme` 动作。
- 存档格式不变（`kapai.settings.v1` 仍是 `{ v: 1, theme }`），旧存档读出来照常能用。
- 玻璃主题的 81 个 CSS 变量全部重写，没有沿用深色残留（否则会露出实心深色板）。

## 门禁

- 新增 4 条主题检查：玻璃写入设置并反映到 documentElement / 设置页三个选项且高亮在玻璃上 / 玻璃变量表完整且有磨砂与光斑背景 / 检查跑完复位成浅色。
- 规则回归测试 86 个全过；打包产物集成测试全过；APK 产物验证全过，并新增一张「玻璃首页」渲染截图（shots/36-apk-home-glass.png）。
