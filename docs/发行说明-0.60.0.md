# 发行说明 · 0.60.0

> **这一版把「两个人得连同一个 Wi-Fi」变成了「两个人各自上网就行」。**
>
> 同一份游戏现在同时是：手机上的 APK（局域网联机）和
> 公网上的网站（房间号联机）。开一个房间，把六位房号念给对面，
> 对方在任何网络下打开都能进来。

---

## 一、公网联机

### 怎么玩

1. 双方各自打开站点（见下方「地址」）；
2. 开始游戏 → 联机对决 → 创建房间；
3. 页面给出六位房间号（例如 `K7QM2P`）和一条邀请链接；
4. 把**房号念给对方**，或把**链接发过去**；
5. 对方进来后，主机点「开始对战」。

房号字母表刻意去掉了 `0/O/1/I` —— 这个号是要口头念的，
`0` 和 `O` 念出来没法区分。

### 为什么这样设计

这个游戏的引擎是**完全确定性**的：所有随机数都来自 `state.rng`，
同一串操作在任何一台机器上跑出来的局面必然一致。
所以联机**不传棋盘，只传操作**，流量小到可以忽略，
也不可能出现「两边看到的棋盘不一样」这种经典同步 bug。

每 8 步双方互发一次 `hash`（回合 / 阶段 / 双方王血 / 手牌数 / 棋盘快照
拼成的 32 位摘要）。一旦对不上，当场停下报错 ——
这比「默默各玩各的、最后一个人说『我怎么输了』」要好。

### 服务端

一个 Cloudflare Worker + 每个房间一个 Durable Object：

- **房间号即路由**：`/api/*?room=K7QM2P` 落到对应的房间对象，
  同一房间的所有操作在这一个对象里**串行**处理，`seq` 不重不漏；
- **长轮询挂起**：没消息就挂着，有消息立刻推下去，不空转；
- **WebSocket 推送**：连得上就用推送，连不上自动回落长轮询；
- **对端离开会叫醒对家**：不用等 20 秒超时；
- 闲置两小时后房间回收。

静态文件（页面、卡图、bundle）由同一个 Worker 的 `ASSETS` 绑定提供，
所以没有跨域、也没有第二个服务要维护。

### 客户端

`Transport` 的每一条请求现在都带 `room`。这一条单独有门禁守着，
因为**局域网服务端根本不看这个参数** —— 漏带一处，
本地全绿、上线全崩，是最难查的那种。

开房 / 进房 / 退房三条路径都加了公网分支：
浏览器里没有安卓原生桥，所以开房靠 URL 导航；
退出房间回站点根路径，而不是 APK 的 `file://` 首页。

## 二、顺带修好的

- **网页版误报「当前环境不支持联机」**：判断可用性时只算了原生桥，
  没算 http/https。现在两处入口都算上了。
- **禁用的主按钮看不出来是禁用的**：以前和可用状态几乎一样，
  现在压暗并去掉发光。
- **邀请链接顶出卡片右侧**：长 URL 没有断行点，现在按字符折行。

## 三、门禁

| 检查 | 数量 | 说明 |
| --- | --- | --- |
| `engine/test/smoke.mjs` | 180 | 引擎规则 |
| `tools/check-bundle.mjs` | 202 | 打包产物集成（新增 15 项） |
| `tools/check-online.mjs` | 27 | 服务端时序：seq / 唤醒 / 离开 / WebSocket |
| `tools/check-online-match.mjs` | 5 | 真打一局，两端每步状态必须一致 |

后两组是**打真请求**的：起一个真实的 workerd，两端各自跑引擎，
每一步比对状态签名。不是 mock。

新增 `tools/checks/37-online.mjs`（15 项），把几处「改一行就悄悄退回局域网语义」
的地方钉死：请求是否带房间号、WebSocket 是否走同一个拼地址函数、
公网分支是否排在原生桥分支之前、退房是否还跳 `file://`。

## 四、地址与访问

线上地址：

```
https://ka-pai.1354817375.workers.dev
```

> ⚠ **中国大陆的网络直连打不开这个域名。**
>
> 实测：`*.workers.dev` 的 DNS 解析被投毒（返回无关的境外 IP），
> 即便手动指到正确的 Cloudflare 边缘 IP，TLS 握手也会因为
> SNI 里含 `workers.dev` 被掐断。
>
> 解决方式二选一：
> 1. **绑自己的域名**（推荐，一次性）：把任意一个域名加进同一个 Cloudflare 账号，
>    在 `cloudflare/wrangler.toml` 里取消注释 `[[routes]]` 那三行、填上域名，
>    再 `npx wrangler deploy` 即可。代码一行都不用改 —— 客户端是从
>    `location` 推导站点地址的。
> 2. **手机开加速器/VPN** 后访问上面的 workers.dev 地址。
>
> 局域网联机（APK 内的老路径）不受影响，它本来就不出公网。
