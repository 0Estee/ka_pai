# 发行说明 0.74.0

> 只动样式，不改规则、不改文案。

## 改动

### 0.64 漏掉的那几个浮层补完（作者 2026-10-25：「统一 ui，有点地方还没改」）

0.64 把**每一屏**都换成了「账本」，但**浮在屏幕上的层**没跟上，还留在 0.62 的
「卷轴与黄铜」里：木纹渐变 + 金边 + 3px 硬投影 + 一个套一个的小方框。这一版按
同一套五条规则（近黑的纸 / 一条头发丝线 / 衬线标题 / 一屏一个实心块 / 金只给当下那一行）补完：

| 位置 | 原来 | 现在 |
|---|---|---|
| **单位详情**（点场上的卡） | 木纹面板 + 金边 + 每条词条一个金边小方块 + 金底黑字的「打出:」标签 | 近黑纸 + 头发丝线分条；词条一行一条；「卡面 / 打出:」是金色小字；唯一的实心块是「关闭」 |
| **中途反问**（开战选目标 / 抉择 / 弃哪张牌 / 召唤落点） | 每个选项一个描边圆角块 | 一行一条 + 头发丝线；召唤落点的底部条同样换成一条线 |
| **精通三选一**（强化工坊） | 每个选项整条描一圈档位色 | 档位颜色只留给名字旁那段小字；选项本身是字 + 线 |
| **对局结算** | 卷轴面板 + 框里套框的奖励块 + 两个渐变小按钮 | 纸 + 线；「再来一局」是唯一实心块，「认输」是一行字 |
| **对局菜单** | 木纹整屏面板 + 金标题 | 近黑纸 + 线 |
| **回放 / 云存档的小按钮** | 有描边有底色的胶囊；「删除」描一圈红边 | 一律是**字**，只有按下去才给一层极淡的底；「删除」只让字变红 |
| **云存档「改数据」抽屉** | 一圈金边 + 深底 | 只留一条上边线（0.64 的口径：提示条改成一行字 + 一条线） |

输入框（云存档 / 回放备注 / 手动连接）也统一成同一个样子：淡底 + 头发丝线，聚焦不描亮边。
全部只读语义变量，所以**浅色 / 玻璃主题自动跟着走**，没有第二份颜色要维护。

### 顶栏 / 状态条 / 阶段条：加收缩规则

三处都是一行 flex + 若干不换行的文字，谁都不许缩。于是内容一多（观战页多一个
「视角：玩家1」、靶场牌库变成三位数、状态文字变长）就往外顶。现在按「标题先缩、
数字和按钮不缩」给了省略号规则：**任何情况下「菜单」「结束阶段」都不会被挤出去**。

（实测 360 / 412 宽度下三处 `scrollWidth === clientWidth`，不再溢出。）
