## 二、批次 B · 交互与规则
- **4 指向性锦囊没有目标不能打**（引擎两侧同步改）：新增 `target_requirements` / `selector_has_candidate` / `spell_target_ok`（GDScript）与 `targetRequirements` / `selectorHasCandidate` / `spellTargetOk`（engine/src/play.js），`get_legal_plays` 与 `play_card` 都拦。抉择卡按「方案」展开，任一条方案走得通即可打（否则 U473/U475 会被误杀）。JS 回归 231 项全绿；`parity` 12 局 891 步逐字节一致；`ai-parity` 6 局 533 步一致。
- **5 长按拖拽出牌**：按下 260ms 或拖出 18px 起拖，幽灵跟手放大 1.08，可落点描金边；落敌方单位 → `targetUid`，落敌方国王 → `targetKing`，落己方格 → `lane/row`，都不中则弹回。引擎侧新增纯查询 `selector_candidates` / `card_target_uids`（不参与对拍）。`ui_input` 实测 DRAG_PLACE / DRAG_SPELL 均 cardsPlayed+1。

## 三、批次 C · 战斗演出
- **3 开战逐线进行**：引擎加 `combat_lane_hook`，每结算完一条线回调；KPSession 每条线发 `lane` 事件并停 `combat_line_pause`（0.62s）；界面按事件队列逐条演（光带 + 线路名 + 攻击者冲锋位移 + 飘字）。`ui_anim` 实测线序 mountain → plainL → plainR → water，间隔 599–610ms。
- **顺带修回放并发推进**：逐线演出让一次 `advance()` 跨数秒，回放驱动器点火即走会二次推进同一局（卡在 DEPLOY_SECOND）。改为 `_advancing` 计数 + `_settle()` 等它落地。`ui_pages` 54 项 0 问题。
